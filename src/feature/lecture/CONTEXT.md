# Lecture Domain — CONTEXT
> 배치 경로: `src/feature/lecture/CONTEXT.md`
> 목적: 이 문서를 읽은 사람 또는 AI 에이전트가 강의 도메인이 **무엇을 하는 도메인이고, 어떤 기능이 있으며, 어떤 조각으로 이루어져 있는지** 파악할 수 있게 한다.
> 구현 상태: 강의 목록과 수정 모달의 정적 UI가 일부 구현되어 있다. 필터 목록 조회, 강의 CRUD API 연동, 등록·상세 조회 모달 연결은 구현 예정이며 실제 구현 상태는 코드 기준으로 갱신한다.

---

## 1. 개요

학원에서 운영하는 강의를 등록하고 관리하는 도메인.

사용자는 강의 관리 페이지에서 강의를 조회하고, 학년·요일·과목·선생님·강의실·학기를 기준으로 목록을 필터링할 수 있다. 강의 등록, 상세 조회, 수정, 삭제 기능을 제공한다.

### 핵심 제약

- 필터의 선택지는 프론트엔드에 고정하지 않고 백엔드 API에서 조회한다.
- 강의 등록과 수정은 동일한 입력 항목을 사용한다.
- 강의 목록의 각 항목을 클릭하면 해당 강의의 상세 조회 모달이 열린다.
- 강의 상세 조회 모달에서는 강의 정보와 수강생을 확인할 수 있다.

### 진입점

Sidebar의 `강의 관리` 메뉴. 메뉴를 클릭하면 강의 관리 페이지로 이동한다.

## 2. 용어

| 용어 | 정의 |
|---|---|
| **강의** | 학년, 과목, 담당 선생님, 강의실, 수강료, 시간표 등의 정보를 가진 수업 단위 |
| **강의 목록** | 필터 조건에 맞는 강의를 표시하는 목록 영역 |
| **필터 목록** | 전체 학년, 전체 요일, 과목, 선생님, 강의실, 학기 선택지. 백엔드 API에서 조회한다 |
| **강의 시간** | 강의가 진행되는 요일과 시작·종료 시간 |
| **수강료 유형** | 월정액, 회당 등 강의 금액을 부과하는 기준 |
| **수강생** | 해당 강의를 수강하는 학생 |

## 3. 화면 구성

강의 관리 페이지는 Filter / Lecture List 구조다.

```
┌─ 강의 관리 페이지 ─────────────────────────────────────┐
│ [Filter]                                      [강의 등록] │
│ [전체 학년] [전체 요일] [과목] [선생님] [강의실] [학기] │
├─────────────────────────────────────────────────────────┤
│ [Lecture List]                                          │
│ 강의명 | 유형 | 학년 | 담당 선생님 | 강의실 | 시간표 ... │
│ 강의 항목                                                │
│ 강의 항목                                                │
└─────────────────────────────────────────────────────────┘
```

### Filter

| 요소 | 설명 |
|---|---|
| 전체 학년 | 학년을 기준으로 강의 목록 필터링 |
| 전체 요일 | 강의 요일을 기준으로 강의 목록 필터링 |
| 과목 | 과목을 기준으로 강의 목록 필터링 |
| 선생님 | 담당 선생님을 기준으로 강의 목록 필터링 |
| 강의실 | 강의실을 기준으로 강의 목록 필터링 |
| 학기 | 학기를 기준으로 강의 목록 필터링 |
| 강의 등록 버튼 | 강의 등록 모달 열기 |

필터 선택지는 백엔드 API에서 조회한다. 선택된 조건은 강의 목록 조회 요청에 전달한다.

### Lecture List

- 필터 조건에 맞는 강의 목록을 표시한다.
- 각 강의 항목에서는 강의명, 유형, 학년, 담당 선생님, 강의실, 시간표, 수강료, 수강생 수를 확인할 수 있다.
- 강의 항목을 클릭하면 해당 강의의 상세 조회 모달이 열린다.

## 6. 컴포넌트 구성

| 컴포넌트 | 책임 | 상태 |
|---|---|---|
| **LectureFilter** | 필터 목록을 표시하고 선택된 조건을 강의 목록 조회에 전달 | 구현 예정 |
| **LectureList** | 강의 목록의 헤더와 강의 항목 렌더링 | 정적 UI 일부 구현 |
| **LectureItem** | 강의 1건의 요약 정보 표시, 클릭 시 상세 조회 모달 열기 | 정적 UI 일부 구현 |
| **ScheduleItem** | 강의 목록에서 요일과 강의 시간 표시 | 정적 UI 일부 구현 |
| **CreateLectureModal** | 강의 등록 입력 폼 표시 | 구현 예정 |
| **ViewLectureModal** | 강의 상세 정보와 수강생 표시, 수정·삭제 진입점 제공 | 구현 예정 |
| **EditLectureModal** | 기존 강의 정보를 입력값으로 표시하고 수정 | 정적 UI 일부 구현 |

### 관계

```
LecturePage
├── LectureFilter
├── 강의 등록 버튼
│   └── CreateLectureModal
└── LectureList
    └── LectureItem
        ├── ScheduleItem
        └── ViewLectureModal
            └── EditLectureModal
```

### 컴포넌트 외 필요한 조각

| 조각 | 역할 | 상태 |
|---|---|---|
| 강의 타입 | 목록·상세·생성·수정 요청과 응답 타입 정의 | 구현 예정 |
| 필터 타입 | 필터 목록 응답과 선택된 필터 조건 정의 | 구현 예정 |
| lecture service | 강의 목록·상세·생성·수정·삭제 및 필터 목록 API 요청 | 구현 예정 |
| lecture actions | 컴포넌트와 lecture service 사이의 Server Action | 구현 예정 |
| 모달 상태 | 등록·상세·수정 모달의 열림/닫힘 관리 | 구현 예정 |

## 8. API 범위

- 필터 목록 조회
- 강의 목록 조회
- 강의 상세 조회
- 강의 생성
- 강의 수정
- 강의 삭제

API 경로, 요청·응답 타입, 오류 처리는 백엔드 명세가 확정된 후 프로젝트의 API 연동 규칙에 맞춰 작성한다.
