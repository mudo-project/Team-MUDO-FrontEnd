# Message Domain — CONTEXT

> 배치 경로: `src/feature/message/CONTEXT.md`
> 목적: 이 문서를 읽은 사람 또는 AI 에이전트가 문자 템플릿 도메인의 목적, 담당 기능, 데이터와 컴포넌트 구성을 파악할 수 있게 한다.
> 구현 상태: 등록·수정 모달의 정적 UI가 존재한다. 목록 조회, 등록, 수정, 삭제와 모달 상태 및 API 연동 여부는 각 구현 파일을 확인해야 한다.

---

## 1. 개요

학생들에게 일괄 발송할 문자 내용을 템플릿으로 관리하는 도메인이다.

문자 템플릿은 출결 상태에 따라 서로 다르게 만들 수 있다. 사용자는 등록된 템플릿을 조회하고 새로운 템플릿을 등록하거나 기존 템플릿을 수정·삭제할 수 있다.

### 핵심 제약

- 템플릿을 등록할 때는 이름, 내용, 출결 상태를 입력한다.
- 템플릿을 수정할 때는 이름과 내용만 변경할 수 있다.
- 템플릿에 지정된 출결 상태는 수정할 수 없다.
- 문자 템플릿은 학생들에게 발송할 문자의 재사용 가능한 형식이다.

### 진입점

- Sidebar의 `메시지 템플릿` 메뉴를 클릭해 메시지 템플릿 페이지로 이동한다.

---

## 2. 용어

| 용어 | 정의 |
|---|---|
| **메시지 템플릿** | 학생에게 일괄 발송할 문자 이름과 내용을 저장한 형식 |
| **출결 상태** | 템플릿이 적용되는 출석 상태. 등록할 때 지정하고 수정할 수 없다 |
| **템플릿 목록** | 등록된 메시지 템플릿을 반복해서 표시하는 영역 |
| **템플릿 등록 모달** | 이름, 내용, 출결 상태를 입력해 새 템플릿을 만드는 모달 |
| **템플릿 수정 모달** | 기존 템플릿의 이름과 내용만 변경하는 모달 |
| **템플릿 삭제** | 더 이상 사용하지 않는 템플릿을 제거하는 기능 |

---

## 3. 화면 구성

메시지 템플릿 페이지는 상단 액션 영역과 템플릿 목록 영역으로 구성된다.

```text
┌─ 메시지 템플릿 페이지 ───────────────────────────┐
│ [상단 액션 영역]                   [템플릿 등록] │
├─────────────────────────────────────────────────┤
│ [템플릿 목록]                                   │
│ ┌─ 템플릿 카드 ─┐  ┌─ 템플릿 카드 ─┐            │
│ │ 이름           │  │ 이름           │            │
│ │ 출결 상태      │  │ 출결 상태      │            │
│ │ 내용           │  │ 내용           │            │
│ │ [수정] [삭제]  │  │ [수정] [삭제]  │            │
│ └────────────────┘  └────────────────┘            │
└─────────────────────────────────────────────────┘
```

### 상단 액션 영역

| 요소 | 설명 |
|---|---|
| 템플릿 등록 버튼 | 새 메시지 템플릿 등록 모달을 연다 |

### 템플릿 목록 영역

- 등록된 메시지 템플릿을 표시한다.
- 각 템플릿에서 이름, 출결 상태와 내용을 확인할 수 있다.
- 각 템플릿에서 수정과 삭제 기능에 진입할 수 있다.

## 4. 기능 목록

### 4.1 페이지 진입

| 기능 | 트리거 | 동작 |
|---|---|---|
| 메시지 템플릿 페이지 이동 | Sidebar의 `메시지 템플릿` 클릭 | 메시지 템플릿 페이지로 이동 |

### 4.2 템플릿 조회

| 기능 | 트리거 | 동작 |
|---|---|---|
| 템플릿 목록 조회 | 메시지 템플릿 페이지 진입 | 등록된 메시지 템플릿 목록 표시 |
| 템플릿 정보 확인 | 목록 확인 | 템플릿 이름, 출결 상태와 문자 내용 표시 |

### 4.3 템플릿 등록

| 기능 | 트리거 | 동작 |
|---|---|---|
| 등록 모달 열기 | 상단 `템플릿 등록` 버튼 클릭 | `CreateMessageTemplateModal` 표시 |
| 템플릿 이름 입력 | 이름 입력란 작성 | 템플릿을 식별할 이름 입력 |
| 출결 상태 선택 | 출결 상태 선택란 변경 | 템플릿이 적용될 출결 상태 지정 |
| 문자 내용 입력 | 내용 입력란 작성 | 학생에게 발송할 문자 내용 입력 |
| 템플릿 등록 | 등록 버튼 클릭 | 이름, 출결 상태와 내용으로 새 템플릿 등록 |
| 등록 취소 | 취소 또는 닫기 버튼 클릭 | 입력을 저장하지 않고 등록 모달 닫기 |

### 4.4 템플릿 수정

| 기능 | 트리거 | 동작 |
|---|---|---|
| 수정 모달 열기 | 템플릿의 수정 버튼 클릭 | 선택한 템플릿의 `EditMessageTemplateModal` 표시 |
| 템플릿 이름 수정 | 이름 입력란 변경 | 기존 템플릿 이름 변경 |
| 문자 내용 수정 | 내용 입력란 변경 | 기존 문자 내용 변경 |
| 템플릿 수정 저장 | 저장 버튼 클릭 | 변경한 이름과 내용 저장 |
| 수정 취소 | 취소 또는 닫기 버튼 클릭 | 변경 사항을 저장하지 않고 수정 모달 닫기 |

> 출결 상태는 등록 시에만 지정한다. 수정 모달에서는 출결 상태를 표시하거나 변경하는 입력을 제공하지 않는다.

### 4.5 템플릿 삭제

| 기능 | 트리거 | 동작 |
|---|---|---|
| 삭제 확인 열기 | 템플릿의 삭제 버튼 클릭 | 선택한 템플릿 삭제 여부 확인 |
| 템플릿 삭제 | 삭제 확인 | 선택한 메시지 템플릿 제거 |
| 삭제 취소 | 취소 클릭 | 템플릿을 유지하고 확인 UI 닫기 |

## 5. 데이터

메시지 템플릿 한 건이 가지는 정보다.

| 항목 | 등록 | 수정 | 설명 |
|---|---|---|---|
| 이름 | 가능 | 가능 | 템플릿을 구분하는 이름 |
| 내용 | 가능 | 가능 | 학생에게 발송할 문자 내용 |
| 출결 상태 | 가능 | 불가능 | 해당 템플릿이 적용되는 출석 상태 |

### 출결 상태

문자 템플릿은 출결 상태별로 서로 다르게 구성할 수 있다. 실제 상태 코드와 표시 문구는 API 타입 또는 도메인 상수를 기준으로 사용한다.

## 6. 컴포넌트 구성

기능 단위로 분해했을 때 필요한 컴포넌트와 책임이다. 아직 존재하지 않는 컴포넌트의 실제 파일명은 구현 과정에서 달라질 수 있다.

| 컴포넌트 | 책임 | 현재 확인 상태 |
|---|---|---|
| **MessageTemplatePage** | 페이지 상단 액션과 템플릿 목록 배치 | 구현 여부 확인 필요 |
| **MessageTemplateCreateButton** | 등록 모달 열기 | 구현 여부 확인 필요 |
| **MessageTemplateList** | 등록된 템플릿 목록 표시 | 구현 여부 확인 필요 |
| **MessageTemplateItem** | 템플릿 한 건의 이름, 출결 상태, 내용과 액션 표시 | 구현 여부 확인 필요 |
| **CreateMessageTemplateModal** | 이름, 출결 상태, 내용을 입력하는 등록 UI | 정적 UI 존재 |
| **EditMessageTemplateModal** | 기존 이름과 내용을 수정하는 UI | 정적 UI 존재 |
| **MessageTemplateDeleteModal** | 삭제 여부 확인 및 삭제 실행 | 구현 여부 확인 필요 |

### 관계

```text
MessageTemplatePage
├── MessageTemplateCreateButton
│   └── CreateMessageTemplateModal
└── MessageTemplateList
    └── MessageTemplateItem
        ├── EditMessageTemplateModal
        └── MessageTemplateDeleteModal
```

### 현재 확인된 파일

| 파일 | 설명 |
|---|---|
| `src/feature/message/components/modals/CreateMessageTemplateModal.tsx` | 템플릿 이름, 출결 상태, 내용 입력과 취소·등록 버튼을 가진 정적 등록 모달 |
| `src/feature/message/components/modals/EditMessageTemplateModal.tsx` | 템플릿 이름과 내용 입력 및 하단 버튼을 가진 정적 수정 모달 |

## 8. 핵심 제약

- 등록 모달에서는 이름, 내용, 출결 상태를 모두 입력할 수 있어야 한다.
- 수정 모달에서는 이름과 내용만 변경할 수 있어야 한다.
- 기존 템플릿의 출결 상태는 수정할 수 없어야 한다.
- 등록·수정·삭제 성공 후에는 화면의 템플릿 목록이 최신 상태를 반영해야 한다.
- 실패한 요청은 사용자가 다시 시도할 수 있도록 입력값과 대상 템플릿을 유지해야 한다.
