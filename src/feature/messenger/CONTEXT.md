# Messenger(메신저) Domain — CONTEXT
> 배치 경로: `src/feature/messenger/CONTEXT.md`
> 목적: 이 문서를 읽은 사람 또는 AI 에이전트가 메신저 도메인이 **무엇을 하는 도메인이고, 어떤 기능이 있으며, 어떤 조각으로 이루어져 있는지** 파악할 수 있게 한다.
> 구현 상태: **부분 구현**. 채팅방 목록·전환, 채팅방 내 검색, 좌측 사이드바(채팅/업무) 전환, 업무지시 작성 폼·상세조회 모달, 파일 선택 다이얼로그 연결, 메시지 우클릭 메뉴 노출까지는 실제 상태로 동작한다. 다만 데이터는 `src/feature/messenger/data.ts`의 더미 데이터이며, 메시지 전송·수정·삭제, 채팅방 생성, 업무지시 등록, 완료 처리, 파일 업로드는 **UI만 연결되어 있고 실제 반영 로직은 없다** (버튼을 눌러도 더미 데이터는 바뀌지 않는다).

---

## 1. 개요

사용자 간 1:1 또는 그룹 채팅과, 채팅방을 매개로 한 업무지시를 다루는 도메인.

채팅으로 대화하는 것과 별개로, 채팅방 안에서 담당자·마감일을 지정해 업무를 지시하고, 지시한/받은 업무의 진행 현황을 추적할 수 있는 것이 이 도메인의 핵심 기능이다.

### 진입점 및 라우팅

- Sidebar의 메신저 메뉴(`src/components/layout/Sidebar.tsx`, `href: "/messenger"`).
- `src/app/(user)/messenger/layout.tsx`가 좌측 사이드바(`MessengerSidebar`)를 상시 렌더링하고, 우측 `{children}`에 선택된 채팅방을 렌더링한다. 좌측 사이드바는 라우트 이동과 무관하게 리마운트되지 않는다.
- `src/app/(user)/messenger/page.tsx`: 채팅방 미지정 시 첫 번째 채팅방(`DEFAULT_CHAT_ID`, 현재는 "전체 공지")을 보여준다.
- `src/app/(user)/messenger/[chatId]/page.tsx`: 채팅 목록에서 특정 채팅방을 클릭하면 `next/link`로 이 라우트로 이동하며 해당 채팅방을 렌더링한다.

### 화면 레이아웃

메신저 화면은 좌우 2단으로 나뉜다.

- **좌측**: 채팅/업무 사이드바. 상단에 채팅·업무·채팅방 추가 버튼이 있고, 하단 목록 영역은 선택된 탭(채팅/업무)에 따라 내용이 교체된다.
- **우측**: 선택된 채팅방의 대화 화면.

## 2. 용어

| 용어 | 정의 |
|---|---|
| **좌측 사이드바** | 채팅 목록 또는 업무 목록을 보여주는 영역. 상단 탭(채팅/업무)에 따라 내용이 바뀐다 |
| **채팅 탭** | 좌측 사이드바 상단 버튼. 선택 시 하단이 채팅방 목록으로 전환 |
| **업무 탭** | 좌측 사이드바 상단 버튼. 클릭 시 바로 아래에 받은 업무/전달한 업무를 고르는 드롭다운이 뜬다 |
| **새 채팅 모달** | 채팅방 추가 버튼 클릭 시 나타나는, 인원을 선택해 채팅방을 만드는 모달 |
| **받은 업무** | 다른 사람이 나에게 지시한 업무 목록 |
| **전달한 업무** | 내가 다른 사람에게 지시한 업무 목록 |
| **업무지시** | 채팅방 내에서 `/` 입력 또는 `+` 버튼으로 진입해 작성하는, 담당자·마감일이 지정된 업무 |
| **업무지시 상세조회 모달** | 받은/전달한 업무 목록, 채팅방 업무지시 카드 세 곳에서 공통으로 열리는 업무지시 상세 모달 |
| **마감 초과** | 받은 업무의 마감일이 지났는데 완료 처리되지 않은 상태 |

## 3. 화면 구성

```
┌─ 메신저 화면 ────────────────────────────────────────────────┐
│ [좌측 사이드바]              │ [우측 채팅방]                  │
│  [채팅] [업무] [채팅방 추가]  │  채팅방 제목  참여자 수  검색  참여자목록 │
│ ──────────────────────────  │ ──────────────────────────────  │
│  (채팅 탭인 경우)             │  상대방: 이름 · 내용 · 시간 · 읽음 수 │
│   검색바                     │  나: 내용 · 시간 (우클릭 시 수정/삭제) │
│   채팅 목록                  │  [업무지시 카드 / 완료 알림 카드]    │
│                              │ ──────────────────────────────  │
│  (업무 탭 클릭 시)            │  [+] [입력창] "/" 입력 또는 + 클릭 시 │
│   업무 버튼 바로 아래에        │       업무지시/사진/파일 메뉴 노출     │
│   [받은 업무][전달한 업무]     │                                  │
│   드롭다운(가로 배치)          │                                  │
└──────────────────────────────────────────────────────────────┘
```

### 좌측 사이드바 — 공통

`MessengerSidebar`가 상단 탭 행(채팅 / 업무 / 채팅방 추가, 높이 51px)을 소유하며, 우측 `ChatRoomHeader`와 같은 높이라 하단 경계선이 나란히 맞는다.

### 좌측 사이드바 — 채팅 탭

검색바, 채팅 목록으로 구성. 채팅 목록 각 항목은 채팅방 제목·마지막 채팅 내용·시간·읽지 않은 채팅 갯수를 표시하며, 클릭하면 `next/link`로 해당 채팅방 라우트(`/messenger/[chatId]`)로 이동한다. 현재 라우트와 일치하는 항목은 강조 배경으로 표시된다.

### 좌측 사이드바 — 업무 탭

"업무" 버튼을 클릭하면 그 버튼 바로 아래에 **absolute로 뜨는 드롭다운**이 나타난다. 드롭다운은 "받은 업무"/"전달한 업무" 두 항목을 **가로로** 나열하며, 하나를 선택하면 드롭다운이 닫히고 좌측 사이드바 하단이 해당 업무 목록으로 바뀐다. 다시 다른 목록으로 바꾸려면 "업무" 버튼을 한 번 더 눌러 드롭다운을 다시 띄운다.

#### 받은 업무 사이드바

검색바, 받은 업무 카드 목록으로 구성. 카드는 상단에 체크 아이콘 + "채팅방 제목 · 지시한 인원", 본문에 지시 내용, 하단 좌측에 날짜(마감 초과 시 빨간색 "마감초과 날짜"), 하단 우측에 상태를 표시한다.

- 완료: 초록 체크 아이콘 + `완료함`
- 미완료 / 마감 초과: `완료했습니다` 버튼 (클릭해도 실제 완료 처리는 아직 없음)
- 카드의 제목·본문 영역 클릭 시 업무지시 상세조회 모달 노출 (`완료했습니다` 버튼은 별도 클릭 영역이라 상세조회를 열지 않는다)

#### 전달한 업무 사이드바

검색바, 전달한 업무 카드 목록으로 구성. 카드는 상단에 체크 아이콘 + 채팅방 이름, 본문에 전달한 업무 내용, 하단에 "완료 N/M" 텍스트 + 진행바를 표시한다.

- 카드의 제목·본문 영역 클릭 시 업무지시 상세조회 모달 노출

### 새 채팅 모달

검색바, "소속 인원" 목록, 채팅방 제목(선택) 입력으로 구성.

- 검색바에 입력 시 이름이 일치하는 소속 인원만 노출
- 일치하는 인원이 없으면 "일치하는 인원이 없습니다" 표시
- 인원 클릭 시 체크박스로 선택 상태 표시(다중 선택)
- 담당자를 1명 이상 선택하기 전에는 `만들기` 버튼이 비활성(회색) 상태

### 우측 채팅방

상단(채팅방 제목·참여자 갯수·검색·참여자 목록), 대화 영역, 하단 입력 영역으로 구성.

- **검색**: 헤더의 검색 아이콘을 클릭하면 제목 영역이 검색 입력창으로 바뀐다. 입력한 검색어로 현재 채팅방의 메시지(일반 텍스트 + 업무지시/완료 카드 내용)를 실시간 필터링하고, 결과가 없으면 "검색 결과가 없습니다"를 표시한다. X 버튼을 누르면 검색어를 지우고 원래 헤더로 돌아온다.
- **참여자 목록**: 헤더의 참여자 아이콘(사람 그룹 아이콘)을 클릭하면 채팅방 우측에 참여자 목록 사이드바(전체 높이, `w-72`)가 열린다.
- **메시지 표시**: 상대방 메시지는 이름·내용·시간·읽은 사람 갯수, 내 메시지는 내용·시간만 표시.
- **내 메시지 수정/삭제**: 내 메시지를 **우클릭**하면 그 자리에 수정/삭제 메뉴가 뜨고, 메뉴 바깥을 클릭하면 자동으로 닫힌다(호버로는 뜨지 않는다). 삭제된 메시지는 "삭제된 채팅입니다"로 대체 표시(현재는 더미 데이터로만 존재, 실제 삭제 액션은 아직 없음).
- **업무지시/완료 카드**: 채팅방 내 업무지시 메시지는 본인이 등록한 경우 우측 정렬, 다른 사람이 등록한 경우 아바타·이름과 함께 좌측 정렬로 표시된다. 완료 알림 카드는 중앙 정렬로 표시된다. 두 카드 모두 클릭하면(업무지시 카드만 클릭 가능) 업무지시 상세조회 모달이 뜬다.
- **입력창 첨부 메뉴**: 입력창에 `/`를 입력하거나 좌측 `+` 버튼을 클릭하면 입력창 바로 위, 입력창과 같은 너비로 업무지시/사진/파일 메뉴가 뜬다.
  - `업무지시` 클릭 → 업무지시 작성 모달
  - `사진` 클릭 → `accept="image/*"` 파일 선택 창 노출
  - `파일` 클릭 → 파일 선택 창 노출
  - (선택된 파일을 실제로 채팅방에 전송하는 로직은 아직 없다)

### 업무지시 작성 모달

내용(textarea), 담당자(+ 추가), 마감일(선택, date input)로 구성.

- `+ 추가` 버튼을 클릭하면 바로 아래에 담당자 선택 드롭다운이 뜬다. 드롭다운은 이름 검색창 + "이 채팅방 참여자만 지정할 수 있습니다" 안내 + 참여자 목록으로 구성되며, 검색 결과가 없으면 "일치하는 인원이 없습니다"를 표시한다.
- 참여자를 클릭하면 담당자로 선택되어 `담당자` 영역에 칩(이름 + 제거 버튼)으로 추가되고, 여러 명을 중복 선택할 수 있다.
- `등록` 클릭 시 실제로 채팅방에 업무지시 메시지를 게시하는 로직은 아직 없다(모달 UI만 완성).

### 업무지시 상세조회 모달

받은 업무 목록, 전달한 업무 목록, 채팅방 업무지시 카드 세 진입점 모두 **동일한 업무지시 데이터**를 보여주는 하나의 모달(`TaskDetailModal`)이다. 각 항목은 `taskId`로 `data.ts`의 `taskDetails`를 조회해서 상세 내용을 가져온다.

- 최상단: 체크 아이콘 + "업무지시" + 채팅방 이름 · 지시자 이름, X 버튼
- 본문: 지시 내용
- 담당자: 이름 칩 목록
- 마감일 / 등록일시
- 완료 현황: "N/M명 완료" + 진행바 + 담당자별 칩(완료 시 체크, 미완료 시 빈 원 아이콘)

> 현재는 역할(지시자/담당자)에 따라 하단 영역을 다르게 렌더링하지 않고, 모든 진입점에서 동일하게 "담당자별 완료 현황"을 보여준다. 역할별 분기(담당자 본인 시점의 완료 처리 버튼 등)는 추후 반영 대상이다.

## 4. 기능 목록

### 4.1 사이드바 탭 전환 — 구현 완료 (UI 전환만, 데이터는 더미)

| 기능 | 트리거 | 동작 |
|---|---|---|
| 채팅 탭 전환 | 좌측 상단 `채팅` 클릭 | 하단 사이드바가 검색바 + 채팅 목록으로 전환 |
| 업무 드롭다운 열기/닫기 | 좌측 상단 `업무` 클릭 | 업무 버튼 바로 아래에 받은 업무/전달한 업무 드롭다운(가로 배치) 노출. 다시 클릭 시 토글 |
| 받은 업무 전환 | 드롭다운에서 `받은 업무` 클릭 | 드롭다운 닫힘 + 좌측 사이드바 하단이 받은 업무 목록으로 전환 |
| 전달한 업무 전환 | 드롭다운에서 `전달한 업무` 클릭 | 드롭다운 닫힘 + 좌측 사이드바 하단이 전달한 업무 목록으로 전환 |

### 4.2 채팅방 생성 — UI 구현 (생성 로직 미구현)

| 기능 | 트리거 | 동작 |
|---|---|---|
| 새 채팅 모달 열기 | 좌측 상단 `채팅방 추가` 클릭 | 검색바·소속 인원·채팅방 제목(선택) 입력 모달 노출 |
| 인원 검색 | 모달 내 검색바 입력 | 이름이 일치하는 소속 인원만 노출 |
| 검색 결과 없음 안내 | 검색 결과 0건 | "일치하는 인원이 없습니다" 표시 |
| 인원 선택 | 소속 인원 클릭 | 체크박스로 선택 상태 표시(다중 선택 가능) |
| 만들기 버튼 활성화 | 담당자 1명 이상 선택 | `만들기` 버튼이 활성(진한 배경) 상태로 전환 |
| 채팅방 생성 | `만들기` 클릭 | (미구현) 실제 채팅방을 만드는 로직 없음 |

### 4.3 채팅 목록 — 구현 완료 (더미 데이터)

| 기능 | 트리거 | 동작 |
|---|---|---|
| 채팅 목록 검색 | 좌측 검색바 입력 | (UI만 존재, 실제 필터링 로직 미구현) |

## 5. 데이터

`src/feature/messenger/data.ts`에 정의되어 있다.

### 채팅방 (`Chat`)

| 항목 | 설명 |
|---|---|
| id | 라우트(`/messenger/[chatId]`)에 쓰이는 식별자 |
| name | 채팅방 목록·채팅방 상단에 표시 |
| participantsCount | 참여자 수 표시 |
| preview | 채팅 목록에 표시되는 마지막 채팅 내용 |
| time | 마지막 채팅 시각 |
| unread | 읽지 않은 채팅 갯수 |
| initials | 아바타 이니셜 |
| messages | 해당 채팅방의 메시지 배열(`ChatMessage[]`) |

### 메시지 (`ChatMessage` = `TextMessage` \| `TaskInstructionMessage` \| `TaskCompletionMessage`, `kind`로 구분)

| 종류 | 주요 항목 | 설명 |
|---|---|---|
| `TextMessage` | sender, initials, time, text, own, readCount, deleted | 일반 대화 메시지. `own`이면 내 메시지(우클릭 메뉴 대상), `deleted`면 "삭제된 채팅입니다"로 렌더링 |
| `TaskInstructionMessage` | taskId, own, instructor, instructorInitials, time, content, confirmed, assigneeCount | 채팅방에 게시된 업무지시 카드. `taskId`로 `taskDetails`를 조회해 상세조회 모달을 연다 |
| `TaskCompletionMessage` | assigneeName, time, content, completed, total | 담당자가 완료했다는 알림 카드(중앙 정렬) |

`getMessageSearchText(message)` 헬퍼가 종류별로 검색 대상 문자열(텍스트 또는 업무지시/완료 내용)을 반환하며, 채팅방 내 검색 필터링에 사용된다.

### 업무지시 상세 (`TaskDetail`, `taskDetails` 배열 + `getTaskDetail(id)`)

| 항목 | 설명 |
|---|---|
| id | `TaskInstructionMessage.taskId`, 받은/전달한 업무 목록의 `taskId`가 참조하는 식별자 |
| chatName | 업무지시가 게시된 채팅방 이름 |
| instructor | 지시자 이름 |
| content | 지시 내용 |
| assignees | `TaskAssignee[]` — 담당자별 이름·이니셜·완료 여부 |
| dueDate | 마감일 |
| createdAt | 등록일시 |

받은/전달한 업무 목록의 카드에 표시되는 상태(완료함/완료했습니다/마감초과, 완료 N/M)는 목록 자체의 더미 필드이며, `taskDetails`의 `assignees` 완료 여부와 반드시 일치하지는 않는다(현재는 각각 독립된 더미 데이터).

## 6. 컴포넌트 구성

`src/feature/messenger/components/`에 실제로 존재하는 컴포넌트 기준.

| 컴포넌트 | 책임 |
|---|---|
| **MessengerSidebar** | 좌측 사이드바 셸(client). 채팅/업무 탭 상태, 업무 드롭다운 열림 상태, 새 채팅 모달 열림 상태를 소유. 탭에 따라 `ChatSidebar` 또는 `TaskSidebar` 렌더링 |
| **ChatSidebar** | 채팅 탭 하단 영역. 검색바 + `ChatList` |
| **ChatList** | `data.ts`의 `chats`를 매핑해 `ChatListItem` 렌더링 |
| **ChatListItem** | 채팅방 목록 항목 1건(client, `next/link`). 현재 라우트와 비교해 활성 표시 |
| **ChatCreateModal** | 새 채팅 모달(client). 이름 검색, 다중 선택, 선택 인원 0명일 때 만들기 버튼 비활성화 |
| **TaskSidebar** | 업무 탭 하단 영역. 검색바 + `view` prop에 따라 `ReceivedTaskList`/`SentTaskList` 렌더링 |
| **ReceivedTaskList** | 받은 업무 카드 목록(client). 카드 클릭 시 `TaskDetailModal`을 `taskId`로 오픈 |
| **SentTaskList** | 전달한 업무 카드 목록(client). 카드 클릭 시 `TaskDetailModal`을 `taskId`로 오픈 |
| **ChatRoom** | 우측 채팅방 셸(client). `chatId`로 `chat`을 조회하고, 검색어 상태를 소유해 메시지를 필터링, Header/MessageList/MessageInput 배치 |
| **ChatRoomHeader** | 채팅방 헤더(client). 평시엔 제목·참여자 수·검색/참여자 아이콘, 검색 모드일 땐 검색 입력창으로 전환. 참여자 아이콘으로 `ChatMemberList` 토글 |
| **ChatMemberList** | 참여자 목록 우측 사이드바(전체 높이, `w-72`) |
| **MessageList** | 전달받은 메시지 배열을 매핑해 `MessageItem` 렌더링 |
| **MessageItem** | 메시지 1건(client). `kind`에 따라 `TaskMessageCard`/`TaskCompletionCard`로 위임하거나, 삭제됨/본인/상대방 상태를 렌더링. 본인 메시지는 우클릭(`onContextMenu`)으로 `MessageMenu`를 열고 바깥 클릭 시 닫음 |
| **MessageMenu** | 내 메시지 메뉴. 수정/삭제 버튼(현재는 클릭 시 메뉴만 닫힘) |
| **TaskMessageCard** | 채팅방 내 업무지시 카드(client). `own` 여부로 좌/우 정렬, 클릭 시 `TaskDetailModal` 오픈 |
| **TaskCompletionCard** | 완료 알림 카드(중앙 정렬) |
| **MessageInput** | 하단 입력 영역(client). `/` 입력 감지 및 `+` 버튼으로 첨부 메뉴 토글, 숨겨진 `input[type=file]` 2개(사진/파일)로 네이티브 파일 선택 연결, `업무지시` 선택 시 `TaskCreateModal` 오픈 |
| **TaskCreateModal** | 업무지시 작성 모달(client). 내용/마감일 입력, `+ 추가`로 담당자 검색·다중 선택 드롭다운 |
| **TaskDetailModal** | 업무지시 상세조회 모달. `taskId`로 `getTaskDetail`을 조회해 렌더링. `ReceivedTaskList`·`SentTaskList`·`TaskMessageCard`가 공유 |
| **Avatar** | 아바타 이니셜 공용 컴포넌트 |

> `TaskDetailModal`은 받은/전달 업무별로 분리하지 않는다. 동일한 업무지시 데이터를 `taskId`로 조회해 재사용하며, 역할별 분기(지시자/담당자 시점 차이)는 아직 없다(섹션 3 참고).
