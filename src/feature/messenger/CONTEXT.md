# Messenger(메신저) Domain — CONTEXT
> 배치 경로: `src/feature/messenger/CONTEXT.md`
> 목적: 이 문서를 읽은 사람 또는 AI 에이전트가 메신저 도메인이 **무엇을 하는 도메인이고, 어떤 기능이 있으며, 어떤 조각으로 이루어져 있는지** 파악할 수 있게 한다.
> 구현 상태: **미구현 (정적 프로토타입)**. `src/app/(user)/messenger/page.tsx`에 더미 데이터를 렌더링하는 화면만 존재한다. 채팅방 생성, 좌측 사이드바(채팅/업무) 전환, 업무지시 작성·조회, 메시지 수정·삭제, 파일·사진 전송 등은 모두 미구현이다. `src/feature/messenger/`는 아직 생성되지 않았다.

## 1. 개요

사용자 간 1:1 또는 그룹 채팅과, 채팅방을 매개로 한 업무지시를 다루는 도메인.

채팅으로 대화하는 것과 별개로, 채팅방 안에서 담당자·마감일을 지정해 업무를 지시하고, 지시한/받은 업무의 진행 현황을 추적할 수 있는 것이 이 도메인의 핵심 기능이다.

### 진입점

Sidebar의 메신저 메뉴(`src/components/layout/Sidebar.tsx`, `href: "/messenger"`). 라우트는 `src/app/(user)/messenger/page.tsx`.

### 화면 레이아웃

메신저 화면은 좌우 2단으로 나뉜다.

- **좌측**: 채팅/업무 사이드바. 상단에 채팅·업무·채팅방 추가 버튼이 있고, 하단 목록 영역은 선택된 탭(채팅/업무)에 따라 내용이 교체된다.
- **우측**: 선택된 채팅방의 대화 화면.

## 2. 용어

| 용어 | 정의 |
|---|---|
| **좌측 사이드바** | 채팅 목록 또는 업무 목록을 보여주는 영역. 상단 탭(채팅/업무)에 따라 내용이 바뀐다 |
| **채팅 탭** | 좌측 사이드바 상단 버튼. 선택 시 하단이 채팅방 목록으로 전환 |
| **업무 탭** | 좌측 사이드바 상단 버튼. 선택 시 하단이 받은 업무/전달한 업무 선택 화면으로 전환 |
| **새 채팅 모달** | 채팅방 추가 버튼 클릭 시 나타나는, 인원을 선택해 채팅방을 만드는 모달 |
| **받은 업무** | 다른 사람이 나에게 지시한 업무 목록 |
| **전달한 업무** | 내가 다른 사람에게 지시한 업무 목록 |
| **업무지시** | 채팅방 내에서 `/` 입력으로 진입해 작성하는, 담당자·마감일이 지정된 업무 |
| **마감 초과** | 받은 업무의 마감일이 지났는데 완료 처리되지 않은 상태 |

## 3. 화면 구성

```
┌─ 메신저 화면 ────────────────────────────────────────────────┐
│ [좌측 사이드바]              │ [우측 채팅방]                  │
│  [채팅] [업무] [채팅방 추가]  │  채팅방 제목  참여자 수  검색  참여자목록 │
│ ──────────────────────────  │ ──────────────────────────────  │
│  (채팅 탭인 경우)             │  상대방: 이름 · 내용 · 시간 · 읽음 수 │
│   검색바                     │  나: 내용 · 시간 (우클릭 시 수정/삭제) │
│   채팅 목록                  │  [업무지시 메시지: 지시자, 시간,     │
│    - 채팅방 제목             │   내용, 완료 갯수, 담당자]          │
│    - 마지막 채팅 내용         │ ──────────────────────────────  │
│    - 시간                    │  [+] [입력창] "/" 입력 시 상단에    │
│    - 읽지 않은 채팅 갯수      │      "업무지시" 문구 노출          │
│                              │                                  │
│  (업무 탭인 경우)             │                                  │
│   검색바                     │                                  │
│   [받은 업무] [전달한 업무]   │                                  │
└──────────────────────────────────────────────────────────────┘
```

### 좌측 사이드바 — 채팅 탭

검색바, 채팅 목록으로 구성. 채팅 목록 각 항목은 채팅방 제목·마지막 채팅 내용·시간·읽지 않은 채팅 갯수를 표시한다.

### 좌측 사이드바 — 업무 탭

채팅 탭과 동일하게 탭 바로 아래 검색바가 있고, 그 아래 받은 업무 / 전달한 업무 두 항목이 나타난다. 이 두 항목은 목록이 아니라 **채팅 탭 ↔ 업무 탭 전환과 같은 방식의 이동 트리거**로, 클릭하면 좌측 사이드바 전체가 해당 업무 사이드바(받은/전달)로 바뀐다.

#### 받은 업무 사이드바

검색바, 받은 업무 목록으로 구성. 목록 각 항목은 채팅방 제목·지시한 인원 이름·지시 내용·날짜·완료 유무를 표시한다.

- 미완료: `완료했습니다` 버튼 노출
- 완료: `완료함` 문구 노출
- 완료 처리 전 기간 초과: `마감 초과` 버튼 노출
- 항목 클릭 시 업무지시 상세조회 모달 노출

#### 전달한 업무 사이드바

검색바, 전달한 업무 목록으로 구성. 목록 각 항목은 채팅방 이름·전달한 업무 내용·완료·완료한 갯수·진행바(완료한 갯수 기준)를 표시한다.

- 항목 클릭 시 업무지시 상세조회 모달 노출

### 새 채팅 모달

검색바, 소속 인원 목록, 채팅방 제목 입력으로 구성.

- 검색바에 입력 시 이름이 일치하는 소속 인원만 노출
- 일치하는 인원이 없으면 "일치하는 인원이 없습니다" 표시
- 인원 클릭 시 선택 상태로 전환(다중 선택)
- `만들기` 클릭 시 선택된 인원 + 자신이 포함된 채팅방 생성

### 우측 채팅방

상단(채팅방 제목·참여자 갯수·검색바·참여자 목록 확인 버튼), 대화 영역, 하단 입력 영역(+ 버튼, 입력창)으로 구성.

- 메시지 표시: 상대방 메시지는 이름·내용·시간·읽은 사람 갯수, 내 메시지는 내용·시간만 표시
- 내 메시지는 우클릭 시 수정/삭제 가능. 삭제된 메시지는 "삭제된 채팅입니다"로 대체 표시
- 입력창에 `/` 입력 시 채팅방 상단에 "업무지시" 문구 노출 → 클릭 시 업무지시 작성 모달
- `+` 버튼 클릭 시 업무지시/사진/파일 전송 선택 가능
  - 업무지시 선택 → 업무지시 작성 모달
  - 사진/파일 선택 → 파일 선택 창에서 선택 후 채팅방에 전송

### 업무지시 작성 모달

내용, 담당자, 마감일 입력으로 구성. 등록 시 채팅방에 업무지시 메시지가 게시된다.

- 자신이 등록한 업무지시: 지시자 이름·시간·내용·완료 갯수·담당자 인원이 함께 표시
- 채팅방의 업무지시 메시지 클릭 시 업무지시 상세조회 모달 노출 가능

### 업무지시 상세조회 모달

받은 업무 목록, 전달한 업무 목록, 채팅방 업무지시 메시지 세 진입점 모두 **동일한 업무지시 데이터**를 보여주는 하나의 모달이다. 백엔드는 진입 경로와 무관하게 같은 업무지시 값을 내려주므로, 모달 내부에서 현재 사용자가 지시자인지 담당자인지에 따라 하단 영역만 다르게 렌더링한다.

- 최상단: 채팅방 이름, 지시자 이름, X 버튼
- 상단: 지시 내용
- 중앙: 담당자, 마감일
- 하단(공통 데이터, 역할에 따라 다르게 표시):
  - 지시자 본인이 볼 때: 담당자별 완료 현황(완료 갯수/진행바)
  - 담당자 본인이 볼 때: 본인의 완료 처리 상태(`완료했습니다` / `완료함` / `마감 초과`)

## 4. 기능 목록

### 4.1 사이드바 탭 전환 — 미구현

| 기능 | 트리거 | 동작 |
|---|---|---|
| 채팅 탭 전환 | 좌측 상단 `채팅` 클릭 | 하단 사이드바가 검색바 + 채팅 목록으로 전환 |
| 업무 탭 전환 | 좌측 상단 `업무` 클릭 | 하단 사이드바가 검색바 + 받은 업무/전달한 업무 선택 화면으로 전환 |
| 받은 업무 전환 | 업무 탭에서 `받은 업무` 클릭 | 좌측 사이드바 전체가 받은 업무 사이드바로 전환 |
| 전달한 업무 전환 | 업무 탭에서 `전달한 업무` 클릭 | 좌측 사이드바 전체가 전달한 업무 사이드바로 전환 |

### 4.2 채팅방 생성 — 미구현

| 기능 | 트리거 | 동작 |
|---|---|---|
| 새 채팅 모달 열기 | 좌측 상단 `채팅방 추가` 클릭 | 검색바·소속 인원·채팅방 제목 입력 모달 노출 |
| 인원 검색 | 모달 내 검색바 입력 | 이름이 일치하는 소속 인원만 노출 |
| 검색 결과 없음 안내 | 검색 결과 0건 | "일치하는 인원이 없습니다" 표시 |
| 인원 선택 | 소속 인원 클릭 | 해당 인원 선택 상태로 전환 |
| 채팅방 생성 | `만들기` 클릭 | 선택된 인원 + 자신이 포함된 채팅방 생성 |

### 4.3 채팅 목록 — 미구현 (더미 데이터)

| 기능 | 트리거 | 동작 |
|---|---|---|
| 채팅 목록 검색 | 좌측 검색바 입력 | 채팅방 제목 기준 필터링 |
| 채팅방 진입 | 채팅 목록 항목 클릭 | 우측 채팅방 화면으로 전환 |

### 4.4 받은 업무 — 미구현

| 기능 | 트리거 | 동작 |
|---|---|---|
| 업무 검색 | 받은 업무 사이드바 검색바 입력 | 받은 업무 목록 필터링 |
| 업무 완료 처리 | 목록 항목 `완료했습니다` 클릭 | 해당 업무 완료 처리, 버튼이 `완료함` 문구로 전환 |
| 마감 초과 표시 | 완료 처리 전 마감일 경과 | `완료했습니다` 버튼이 `마감 초과` 버튼으로 전환 |
| 업무지시 상세조회 | 목록 항목 클릭 | 업무지시 상세조회 모달 노출(담당자 관점: 본인 완료 상태 표시) |

### 4.5 전달한 업무 — 미구현

| 기능 | 트리거 | 동작 |
|---|---|---|
| 업무 검색 | 전달한 업무 사이드바 검색바 입력 | 전달한 업무 목록 필터링 |
| 업무지시 상세조회 | 목록 항목 클릭 | 업무지시 상세조회 모달 노출(지시자 관점: 담당자별 완료 현황 표시) |
| 모달 닫기 | 모달 최상단 X 클릭 | 모달 닫힘 |

### 4.6 채팅방 대화 — 미구현 (더미 데이터)

| 기능 | 트리거 | 동작 |
|---|---|---|
| 채팅방 검색 | 채팅방 상단 검색바 입력 | 해당 채팅방 내 메시지 검색 |
| 참여자 목록 확인 | 상단 참여자 목록 확인 버튼 클릭 | 참여자 목록 노출 |
| 메시지 전송 | 입력창에 입력 후 전송 | 채팅방에 내 메시지(내용·시간) 게시 |
| 메시지 수정 | 내 메시지 우클릭 → `수정` | 해당 메시지 내용 수정 |
| 메시지 삭제 | 내 메시지 우클릭 → `삭제` | 해당 메시지가 "삭제된 채팅입니다" 문구로 대체 |

### 4.7 업무지시 — 미구현

| 기능 | 트리거 | 동작 |
|---|---|---|
| 업무지시 문구 노출 | 입력창에 `/` 입력 | 채팅방 상단에 "업무지시" 문구 노출 |
| 업무지시 작성 모달 열기 | "업무지시" 문구 클릭, 또는 `+` 버튼 → `업무지시` 선택 | 내용·담당자·마감일 입력 모달 노출 |
| 업무지시 등록 | 모달에서 내용·담당자·마감일 입력 후 등록 | 채팅방에 업무지시 메시지 게시. 자신이 등록한 경우 지시자 이름·시간·내용·완료 갯수·담당자가 표시 |
| 업무지시 상세조회 | 채팅방 내 업무지시 메시지 클릭 | 업무지시 상세조회 모달 노출 |

### 4.8 파일·사진 전송 — 미구현

| 기능 | 트리거 | 동작 |
|---|---|---|
| 전송 옵션 열기 | 입력창 좌측 `+` 버튼 클릭 | 업무지시/사진/파일 선택 옵션 노출 |
| 사진·파일 전송 | `+` → `사진` 또는 `파일` 선택 | 파일 선택 창 노출, 선택한 파일이 채팅방에 전송 |

| 항목 | 설명 |
|---|---|
| 제목 | 채팅방 목록·채팅방 상단에 표시 |

| 항목 | 설명 |

| 작성자 | 상대방 메시지에만 표시 |
| 내용 | 메시지 본문. 삭제 시 "삭제된 채팅입니다"로 대체 |
| 시간 | 메시지 전송 시각 |
| 읽은 사람 갯수 | 상대방 메시지에 표시 |
| 첨부(사진/파일) | `+` 버튼을 통해 전송된 사진 또는 파일 |

### 업무지시

| 항목 | 설명 |
|---|---|
| 지시자 | 업무지시를 등록한 인원. 자신이 등록한 경우 채팅방 메시지에 이름 표시 |
| 담당자 | 업무지시 작성 시 지정하는 인원(1명 이상 가능) |
| 내용 | 지시 내용 |
| 마감일 | 업무지시 작성 시 지정 |
| 완료 갯수 | 담당자 중 완료 처리한 인원 수. 전달한 업무 목록의 진행바 기준값 |
| 완료 여부 | 담당자별 완료 처리 상태. 받은 업무 목록에서 `완료했습니다`/`완료함`/`마감 초과`로 표현 |

## 6. 컴포넌트 구성

기능 단위로 분해했을 때 필요한 컴포넌트 목록과 각자의 책임. `src/feature/messenger/`는 아직 생성되지 않아 아래는 구현 시 따를 구조 제안이다.

| 컴포넌트 | 책임 |
|---|---|
| **MessengerPage** | 메신저 화면 셸. 좌측 사이드바와 우측 채팅방을 배치. 현재 `src/app/(user)/messenger/page.tsx`가 더미 데이터로 이 역할을 대신하고 있음 |
| **MessengerSidebar** | 좌측 사이드바 셸. 상단 채팅/업무 탭과 채팅방 추가 버튼, 선택된 탭에 따라 `ChatSidebar` 또는 `TaskSidebar`를 렌더링 |
| **ChatSidebar** | 채팅 탭 하단 영역. 검색바 + `ChatList` |
| **ChatList** | 채팅방 목록. 항목 클릭 시 우측 채팅방 전환 |
| **ChatListItem** | 채팅방 목록 항목 1건. 제목·마지막 채팅 내용·시간·읽지 않은 채팅 갯수 표시 |
| **ChatCreateModal** | 새 채팅 모달. 검색바로 소속 인원을 필터링하고, 선택된 인원 + 본인으로 채팅방 생성 |
| **TaskSidebar** | 업무 탭 하단 영역. 검색바 + 받은 업무/전달한 업무 선택, 선택된 항목에 따라 `ReceivedTaskList` 또는 `SentTaskList`를 렌더링 |
| **ReceivedTaskList** | 받은 업무 목록. 완료/마감초과 상태에 따른 버튼 렌더링, 항목 클릭 시 `TaskDetailModal` 노출 |
| **SentTaskList** | 전달한 업무 목록. 완료 갯수 기반 진행바 표시, 항목 클릭 시 `TaskDetailModal` 노출 |
| **ChatRoom** | 우측 채팅방 셸. Header + 대화 영역 + 입력 영역 배치 |
| **ChatRoomHeader** | 채팅방 제목·참여자 갯수·검색바·참여자 목록 확인 버튼 |
| **ChatMemberList** | 참여자 목록 확인 시 노출되는 참여자 목록 |
| **MessageList** | 채팅방 메시지 목록. 상대방/내 메시지, 업무지시 메시지를 구분해 렌더링 |
| **MessageItem** | 메시지 1건(상대방/나). 삭제된 메시지는 "삭제된 채팅입니다" 렌더링 |
| **MessageMenu** | 내 메시지 우클릭 메뉴. 수정/삭제 |
| **TaskMessageCard** | 채팅방 내 업무지시 메시지. 지시자·시간·내용·완료 갯수·담당자 표시, 클릭 시 `TaskDetailModal` 노출 |
| **MessageInput** | 하단 입력 영역. `+` 버튼(업무지시/사진/파일), `/` 입력 감지 및 "업무지시" 문구 노출, 메시지 전송 |
| **TaskCreateModal** | 업무지시 작성 모달. 내용·담당자·마감일 입력 |
| **TaskDetailModal** | 업무지시 상세조회 모달. `ReceivedTaskList`·`SentTaskList`·`TaskMessageCard` 세 진입점이 공유하는 단일 컴포넌트로, 동일한 업무지시 데이터를 현재 사용자의 역할(지시자/담당자)에 따라 다르게 렌더링 |

> `memo`/`notice` 도메인이 작성 폼과 수정 폼(또는 생성/수정 모달)을 분리해 쓰는 것과 동일하게, 업무지시도 작성용 `TaskCreateModal`을 기준으로 하되 수정이 필요해지면 동일한 패턴으로 분리한다.
> `TaskDetailModal`은 받은/전달 업무별로 분리하지 않는다. 백엔드가 진입 경로와 무관하게 동일한 업무지시 데이터를 내려주므로, 역할별 분기를 컴포넌트 내부 조건 렌더링으로 처리해 중복을 없앤다.

### 관계

```
MessengerPage
├── MessengerSidebar
│   ├── ChatSidebar                  (채팅 탭)
│   │   └── ChatList
│   │       └── ChatListItem[]
│   └── TaskSidebar                  (업무 탭, 검색바 + 받은/전달 선택)
│       ├── ReceivedTaskList         (받은 업무 선택 시)
│       │   └── TaskDetailModal      (항목 클릭 시)
│       └── SentTaskList             (전달한 업무 선택 시)
│           └── TaskDetailModal      (항목 클릭 시)
├── ChatCreateModal                  (채팅방 추가 클릭 시)
└── ChatRoom
    ├── ChatRoomHeader
    │   └── ChatMemberList           (참여자 목록 확인 클릭 시)
    ├── MessageList
    │   ├── MessageItem[]
    │   │   └── MessageMenu          (내 메시지 우클릭 시)
    │   └── TaskMessageCard[]
    │       └── TaskDetailModal      (업무지시 메시지 클릭 시)
    └── MessageInput
        └── TaskCreateModal          ("업무지시" 문구 또는 + → 업무지시 선택 시)
```

### 컴포넌트 외 필요한 조각

| 조각 | 역할 | 상태 |
|---|---|---|
| 좌측 사이드바 탭 상태 | 채팅/업무 중 어떤 탭이 선택되었는지, 업무 탭 내에서는 받은/전달한 업무 중 무엇이 선택되었는지 | 미구현 |
| 채팅방 데이터 | 채팅방 목록, 참여자, 생성 | 미구현 (더미 데이터) |
| 메시지 데이터 | 채팅방별 메시지 목록, 전송/수정/삭제 | 미구현 (더미 데이터) |
| 소속 인원 데이터 | 새 채팅 모달의 검색 대상 인원 목록 | 미구현 |
| 업무지시 데이터 | 채팅방과 연결된 업무지시, 담당자별 완료 상태. 진입 경로(받은/전달/채팅 메시지)와 무관하게 동일한 값을 받아오고, 현재 사용자 id로 지시자/담당자 역할을 판별 | 미구현 |
| 슬래시(`/`) 명령 감지 | 입력창에서 `/` 입력을 감지해 "업무지시" 문구를 노출하는 로직 | 미구현 |
| 파일 업로드 | 사진/파일 선택 및 채팅방 전송 | 미구현 |
