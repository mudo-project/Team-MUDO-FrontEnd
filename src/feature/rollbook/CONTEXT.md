# Rollbook Domain — CONTEXT

> 배치 경로: `src/feature/rollbook/CONTEXT.md`
> 목적: 이 문서를 읽은 사람 또는 AI 에이전트가 출석부 도메인의 목적, 화면 구성, 담당 기능과 주요 상태를 파악할 수 있게 한다.

---

## 1. 개요

사용자가 각 강의의 출석부와 학생별 출결 현황을 관리하는 도메인이다.

출석부 페이지에서는 조건에 맞는 강의를 조회하고, 선택한 강의의 전체 출결 현황과 학생별 출결 상태를 확인할 수 있다. 학생의 출결 상태와 비고를 수정·저장할 수 있으며, 출결 결과에 따라 대상 학생을 선택해 문자를 발송할 수 있다.

### 진입점

- Sidebar의 `출석부` 메뉴를 클릭해 출석부 페이지로 이동한다.

### 핵심 기능

- 조건별 강의 필터링
- 강의 목록 조회
- 강의별 출석 현황 조회
- 학생별 출결 상태 변경 및 저장
- 학생별 비고 입력 및 저장
- 문자 발송 대상 선택
- 선택된 학생에게 출결 문자 발송

---

## 2. 용어

| 용어 | 정의 |
|---|---|
| **출석부 페이지** | 강의 필터와 강의 목록을 확인하는 도메인의 기본 화면 |
| **강의 컴포넌트** | 강의 목록에서 강의 한 건의 정보를 표시하는 단위 |
| **출석 현황 모달** | 선택한 강의의 전체 출결 현황과 학생별 출결 정보를 확인·수정하는 모달 |
| **출결 상태** | 학생의 출석 여부를 나타내는 상태 |
| **비고** | 출결과 관련된 기타 사유나 추가 설명을 기록하는 값 |
| **문자 발송 대상** | 출결 문자를 받을 학생으로 선택된 인원 |

---

## 3. 화면 구성

출석부 페이지는 강의 필터 영역과 강의 목록 영역으로 구성된다.

```text
┌─ 출석부 페이지 ───────────────────────────────────┐
│ [강의 필터]                                       │
│ 학년 · 요일 · 과목명 · 선생님 이름 · 강의실 · 학기 │
├───────────────────────────────────────────────────┤
│ [강의 목록]                                       │
│ ┌─ 강의 ─────────┐  ┌─ 강의 ─────────┐            │
│ │ 강의 정보       │  │ 강의 정보       │            │
│ └────────────────┘  └────────────────┘            │
└───────────────────────────────────────────────────┘
```

### 강의 필터 영역

다음 조건을 기준으로 강의 목록을 필터링할 수 있다.

| 필터 | 설명 |
|---|---|
| 학년 | 수강 대상 학년 기준 |
| 요일 | 강의 진행 요일 기준 |
| 과목명 | 강의 과목 기준 |
| 선생님 이름 | 담당 선생님 기준 |
| 강의실 | 강의가 진행되는 강의실 기준 |
| 학기 | 강의가 속한 학기 기준 |

### 강의 목록 영역

- 필터 조건에 맞는 강의 목록을 표시한다.
- 목록 안에는 강의별 컴포넌트가 반복해서 나타난다.
- 강의 컴포넌트를 클릭하면 해당 강의의 출석 현황 모달을 연다.

## 4. 기능 목록

### 4.1 출석부 페이지 진입

| 기능 | 트리거 | 동작 |
|---|---|---|
| 출석부 페이지 이동 | Sidebar의 `출석부` 클릭 | 출석부 페이지로 이동 |

### 4.2 강의 필터링

| 기능 | 트리거 | 동작 |
|---|---|---|
| 학년 필터 | 학년 선택 | 선택한 학년에 해당하는 강의 표시 |
| 요일 필터 | 요일 선택 | 선택한 요일에 진행되는 강의 표시 |
| 과목명 필터 | 과목명 선택 또는 입력 | 선택한 과목의 강의 표시 |
| 선생님 필터 | 선생님 이름 선택 또는 입력 | 해당 선생님이 담당하는 강의 표시 |
| 강의실 필터 | 강의실 선택 | 선택한 강의실에서 진행되는 강의 표시 |
| 학기 필터 | 학기 선택 | 선택한 학기에 해당하는 강의 표시 |

### 4.3 강의 출석 현황 조회

| 기능 | 트리거 | 동작 |
|---|---|---|
| 출석 현황 모달 열기 | 강의 컴포넌트 클릭 | 선택한 강의의 출석 현황 모달 표시 |
| 전체 현황 확인 | 출석 현황 모달 진입 | 해당 강의의 전체 출결 현황 표시 |
| 학생별 현황 확인 | 출석 현황 모달 진입 | 강의에 속한 학생별 출결 상태와 비고 표시 |

### 4.4 학생별 출결 관리

| 기능 | 트리거 | 동작 |
|---|---|---|
| 출결 상태 변경 | 학생의 출결 상태 선택 | 선택한 학생의 출결 상태 변경 |
| 비고 입력 | 학생의 비고 입력란 작성 | 결석 사유 등 기타 내용을 입력 |
| 출결 정보 저장 | 저장 버튼 클릭 | 변경한 학생별 출결 상태와 비고 저장 |

### 4.5 출결 문자 발송

| 기능 | 트리거 | 동작 |
|---|---|---|
| 문자 발송 대상 목록 열기 | `출결 문자 발송` 버튼 클릭 | 문자를 발송할 수 있는 학생 목록 표시 |
| 발송 대상 초기 선택 | 문자 발송 목록 진입 | 문자 발송이 가능한 학생을 모두 선택된 상태로 표시 |
| 발송 대상 변경 | 학생 체크박스 선택 또는 해제 | 해당 학생을 문자 발송 대상에 포함하거나 제외 |
| 문자 발송 | 문자 발송 실행 버튼 클릭 | 현재 체크된 학생들에게만 출결 문자 발송 |

## 6. 컴포넌트 구성

기능 단위로 분해했을 때 필요한 컴포넌트와 책임이다. 실제 파일명은 구현 구조에 따라 달라질 수 있다.

| 컴포넌트 | 책임 |
|---|---|
| **RollbookPage** | 출석부 페이지 전체 구성 및 강의 필터·목록 배치 |
| **LectureFilter** | 학년, 요일, 과목명, 선생님 이름, 강의실, 학기 필터 입력 관리 |
| **LectureList** | 필터 조건에 맞는 강의 목록 표시 |
| **LectureItem** | 강의 한 건 표시 및 클릭 시 출석 현황 모달 열기 |
| **AttendanceStatusModal** | 선택한 강의의 전체·학생별 출결 현황 조회 및 관리 |
| **StudentAttendanceItem** | 학생 한 명의 출결 상태와 비고 입력 관리 |
| **AttendanceMessageModal** | 문자 발송 대상 학생 목록과 선택 상태 관리 |

### 관계

```text
RollbookPage
├── LectureFilter
└── LectureList
    └── LectureItem
        └── AttendanceStatusModal
            ├── StudentAttendanceItem
            └── AttendanceMessageModal
```

| 문자 발송 대상 | 학생별 선택 / 해제. 최초 진입 시 전체 선택 |

---

## 8. 핵심 제약

- 강의 컴포넌트를 선택해야 해당 강의의 출석 현황을 확인할 수 있다.
- 출결 상태와 비고는 학생별로 변경할 수 있어야 한다.
- 문자 발송 대상 목록은 처음 열릴 때 모든 발송 가능 학생이 선택된 상태여야 한다.
- 문자는 최종적으로 체크된 학생들에게만 발송되어야 한다.
