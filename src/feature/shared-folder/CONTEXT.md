# Shared Folder(공유폴더) Domain — CONTEXT
> 배치 경로: `src/feature/shared-folder/CONTEXT.md`
> 목적: 이 문서를 읽은 사람 또는 AI 에이전트가 공유폴더 도메인이 **무엇을 하는 도메인이고, 어떤 기능이 있으며, 어떤 조각으로 이루어져 있는지** 파악할 수 있게 한다.

---

## 1. 개요

학원의 자료(폴더·파일)를 한곳에서 관리하는 도메인. Google Drive와 연동해 폴더 추가·삭제·이동, 자료 추가·삭제·이동을 수행한다.

화면 디자인과 조작 방식은 Google Drive를 따른다 — 상단 검색바·필터·새로만들기, 그 아래 파일경로와 폴더/파일 목록으로 구성된 저장소 컨테이너 구조다.

### 핵심 제약

- 폴더/파일의 실제 저장·관리 주체는 Google Drive이며, 이 도메인은 그 위에 올라가는 UI다. 다운로드 등 세부 동작은 API 명세서를 따른다.
- 파일의 종류는 Google Docs, Google Sheets, Google Slides, 사용자가 업로드한 파일 네 가지로 구분되며, 종류에 따라 아이콘과 "종류" 표시값이 달라진다. 폴더의 "종류" 값은 항상 고정값이다.
- 폴더·파일의 크기가 없거나 알 수 없는 경우 "-"로 표시한다.
- 새 폴더 생성, Google Docs/Sheets/Slides 생성, 파일 업로드는 모두 **현재 위치한 경로**를 기준으로 그 경로에 생성된다.

### 진입점

Sidebar의 공유폴더 메뉴를 클릭해 공유폴더 화면으로 이동할 수 있다. (`src/components/layout/Sidebar.tsx`에 아직 공유폴더 메뉴 항목이 없어 미구현 상태다.)

## 2. 용어

| 용어 | 정의 |
|---|---|
| **저장소 컨테이너** | 화면 상단(검색바·필터·새로만들기) 아래에 위치하는, 파일경로와 폴더/파일 목록을 보여주는 영역 |
| **필터 탭** | 상단 툴바의 전체/폴더/파일 탭. 현재는 시각적 표시만 있고 실제로 목록을 걸러내지는 않는다 |
| **파일경로** | 저장소 컨테이너 최상단에 표시되는 현재 위치 경로 |
| **제목 행** | 이름·종류·수정자·수정일·크기·케밥 메뉴 공간(화면상 빈 값)으로 구성된 목록 헤더 |
| **내용 행** | 폴더 또는 파일 1건을 표시하는 행. 폴더/파일 여부에 따라 표시되는 값이 다르다 |
| **케밥 메뉴** | 내용 행 우측의 `⋮` 버튼과 그 하위 메뉴. 폴더는 이름 변경/이동/삭제, 파일은 상세 보기/미리보기 열기/다운로드/이름 변경/이동/삭제 |
| **새로만들기 컨테이너** | 상단 `새로 만들기` 버튼 클릭 시 나타나는, 새 폴더/Google Docs/Google Sheets/Google Slides/파일 업로드 선택 영역 |
| **이름 변경 모달** | 폴더 또는 파일의 이름을 바꾸는 모달. 입력창에 현재 이름이 채워진 상태로 열린다 |
| **이동 모달** | 폴더 또는 파일을 다른 폴더로 옮기는 모달. 현재 폴더 구조를 보여주며 폴더를 클릭하면 그 하위로 경로가 이동한다 |
| **삭제 확인 모달** | 폴더 또는 파일 삭제 전 확인하는 모달. 삭제 대상 이름, 삭제되는 하위 항목 안내, 안내 문구가 함께 나타난다 |
| **새 폴더 만들기 모달** | 새 폴더 클릭 시 나타나는, 현재 위치와 폴더 이름을 입력하는 모달 |
| **Docs/Sheets/Slides 만들기 모달** | Google Docs/Sheets/Slides 클릭 시 나타나는, 파일 이름을 입력하는 모달 |
| **새 탭에서 열기 모달** | Docs/Sheets/Slides 만들기 완료 후 나타나는, 새 탭에서 해당 파일을 열지 안내하는 모달 |

## 3. 화면 구성

```
┌─ 공유폴더 화면 ──────────────────────────────────────────┐
│ [검색바]              [필터]         [새로 만들기]        │
├───────────────────────────────────────────────────────────┤
│ [저장소 컨테이너]                                         │
│  파일경로: 루트 / 폴더A / 폴더B                           │
│ ───────────────────────────────────────────────────────── │
│  이름          | 종류        | 수정자 | 수정일  | 크기 | ⋮ │
│  📁 폴더 이름  | 폴더        | 김지수 | 08.01   | -    | ⋮ │
│  📄 문서 이름  | Google Docs | 정다은 | 07.30   | -    | ⋮ │
│  📄 업로드 파일| PDF 등      | 정다은 | 07.29   | 2.3MB| ⋮ │
└───────────────────────────────────────────────────────────┘
```

- 폴더 안에 아무 항목도 없으면 "파일이 없습니다" 문구와 함께 파일 업로드/폴더 만들기 버튼을 표시한다.

### 내용 행 — 폴더

폴더 아이콘, 폴더 제목, 종류(고정값 "폴더"), 수정자 이름, 수정일 날짜, 크기(없으면 "-"), 케밥 메뉴로 구성된다.

### 내용 행 — 파일

종류별 아이콘, 파일 제목, 종류(Google Docs/Google Sheets/Google Slides/업로드 파일 종류에 따라 표시), 수정자 이름, 수정일 날짜, 크기(없거나 알 수 없으면 "-"), 케밥 메뉴로 구성된다.

## 6. 컴포넌트 구성

`src/feature/shared-folder/components/`에 실제로 존재하는 컴포넌트 기준. 아직 API 연동이 없어 `SharedFolderBoard`가 화면에 필요한 mock 데이터를 직접 들고 있다.

| 컴포넌트 | 책임 |
|---|---|
| **SharedFolderBoard** | 화면 최상위 컴포넌트(server, 상태 없음). 저장소 컨테이너 영역(파일경로·제목행·목록을 감싸는 카드)의 마크업을 직접 그리고, mock 배열을 `SharedFolderList`에 전달한다 |
| **SharedFolderToolbar** | 상단 검색바·필터 탭·새로 만들기 버튼을 표시(모두 정적, 클릭 이벤트 없음) |
| **SharedFolderPath** | 저장소 컨테이너 최상단의 폴더 경로(breadcrumb) 표시. 현재는 "공유파일 루트" 고정 텍스트만 표시한다 |
| **SharedFolderListHeader** | 이름·종류·수정자·수정일·크기 제목행 |
| **SharedFolderList** | `items`를 받아 `SharedFolderItem`으로 매핑, 목록이 비어 있으면 "파일이 없습니다" 문구를 표시 |
| **SharedFolderItem** | 폴더/파일 내용 행 1건(정적). 종류별 아이콘 배지(폴더/Google Docs/Google Sheets/Google Slides/업로드 파일)와 케밥 아이콘을 표시하며, 클릭 이벤트는 없다. 종류별 표시 라벨(`FILE_TYPE_LABEL`)을 export해 `SharedFolderCreateGoogleModal`과 공유한다 |

> `SharedFolderCreateMenu`(새로 만들기 클릭 시 나타나는 컨테이너), `SharedFolderItemMenu`(케밥 메뉴 내용), `SharedFolderCreateNewFolderModal`/`SharedFolderCreateGoogleModal`/`SharedFolderOpenNewTabModal`(새로 만들기 흐름의 모달 3종)은 컴포넌트 파일만 만들어 두고 화면에는 아직 연결하지 않았다 — 현재 화면은 `SharedFolderBoard`~`SharedFolderItem`까지만 정적으로 렌더링한다. 이름 변경/이동/삭제 확인 모달(`SharedFolderEditNameModal`, `SharedFolderMoveModal`, `SharedFolderDeleteCheckModal`)은 아직 파일 자체가 없다.

### 관계

```
SharedFolderBoard                     (상태 없음, mock 데이터 보유)
├── SharedFolderToolbar               (검색바·필터 탭·새로 만들기 버튼, 모두 정적)
└── (저장소 컨테이너 — Board가 직접 마크업)
    ├── SharedFolderPath
    ├── SharedFolderListHeader
    └── SharedFolderList
        └── SharedFolderItem[]        (케밥 아이콘 표시만, 클릭 이벤트 없음)
```

미연결 상태로 남아 있는 컴포넌트(향후 화면별 PR에서 연결 예정): `SharedFolderCreateMenu`, `SharedFolderItemMenu`, `SharedFolderCreateNewFolderModal`, `SharedFolderCreateGoogleModal`, `SharedFolderOpenNewTabModal`.

### 컴포넌트 외 필요한 조각

| 조각 | 역할 | 상태 |
|---|---|---|
| 폴더/파일 목록 데이터 | Google Drive 연동 조회 | 미구현 — `SharedFolderBoard`의 mock 배열 사용 |
| 필터링 로직 | 필터 탭 선택에 따라 목록을 걸러 보여주는 로직 | 미구현 |
| 현재 경로 탐색 | 폴더 진입/생성/이동에 따른 경로 갱신 | 미구현 |
| 케밥 메뉴·새로 만들기 컨테이너·모달 열기/닫기 | 클릭에 반응해 메뉴·모달을 표시하는 상호작용 | 미구현 — 컴포넌트는 있으나 화면에 연결되지 않음 |
| 새 폴더/Docs·Sheets·Slides 실제 생성, 새 탭 열기 | Google Drive에 실제로 항목을 만들고 여는 동작 | 미구현 |
| 이름 변경/이동/삭제 모달과 실제 조작 | 케밥 메뉴에서 이어지는 나머지 조작 | 미구현 |
