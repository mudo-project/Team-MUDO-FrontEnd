# Shared Folder(공유폴더) Domain — CONTEXT
> 배치 경로: `src/feature/shared-folder/CONTEXT.md`
> 목적: 이 문서를 읽은 사람 또는 AI 에이전트가 공유폴더 도메인이 **무엇을 하는 도메인이고, 어떤 기능이 있으며, 어떤 조각으로 이루어져 있는지** 파악할 수 있게 한다.

---

## 1. 개요

학원의 자료(폴더·파일)를 한곳에서 관리하는 도메인. Google Drive와 연동해 폴더 추가·삭제·이동, 자료 추가·삭제·이동을 수행하는 것을 목표로 한다.

화면 디자인과 조작 방식은 Google Drive를 따른다 — 상단 검색바·필터·새로만들기, 그 아래 파일경로와 폴더/파일 목록으로 구성된 저장소 컨테이너 구조다.

현재는 Google Drive API 연동이 없다. `SharedFolderBoard`가 들고 있는 in-memory mock 데이터(React state)로 폴더 생성·진입·이동·삭제, 파일 생성·업로드·이름변경까지 화면 위에서 실제로 동작하지만, 새로고침하면 초기 mock 목록으로 되돌아간다.

### 핵심 제약

- 폴더/파일의 실제 저장·관리 주체는 Google Drive가 될 예정이며, 지금은 그 자리를 프론트 state가 대신한다.
- 파일의 종류는 Google Docs, Google Sheets, Google Slides, 사용자가 업로드한 파일 네 가지로 구분되며, 종류에 따라 아이콘과 "종류" 표시값이 달라진다. 폴더의 "종류" 값은 항상 고정값이다.
- 폴더·파일의 크기가 없거나 알 수 없는 경우 "-"로 표시한다. 업로드한 파일은 실제 파일 크기를 B/KB/MB 단위로 계산해 표시한다.
- 새 폴더 생성, Google Docs/Sheets/Slides 생성, 파일 업로드는 모두 **현재 위치한 경로**를 기준으로 그 경로에 생성된다.
- 폴더를 삭제하거나 이동하면 하위 폴더·파일도 함께 삭제·이동된다(하위 항목 id를 재귀로 모아 처리).
- 폴더는 자기 자신이나 자신의 하위 폴더로는 이동할 수 없다(이동 모달의 대상 목록에서 제외).
- 수정자는 로그인 연동이 없어 모든 생성·이름변경·이동이 "김서준"으로 고정 기록된다.

### 진입점

Sidebar의 공유폴더 메뉴를 클릭해 공유폴더 화면으로 이동할 수 있다. (`src/components/layout/Sidebar.tsx`에 아직 공유폴더 메뉴 항목이 없어 미구현 상태다.)

## 2. 용어

| 용어 | 정의 |
|---|---|
| **저장소 컨테이너** | 화면 상단(검색바·필터·새로만들기) 아래에 위치하는, 파일경로와 폴더/파일 목록을 보여주는 영역 |
| **필터 탭** | 상단 툴바의 전체/폴더/파일 탭. 클릭하면 현재 폴더의 목록을 종류별로 걸러 보여준다 |
| **파일경로** | 저장소 컨테이너 최상단에 표시되는 현재 위치 breadcrumb. "공유파일 루트"와 하위 폴더들이 `/`로 이어지며, 각 구간을 클릭하면 그 경로로 이동한다 |
| **제목 행** | 이름·종류·수정자·수정일·크기·케밥 메뉴 공간(화면상 빈 값)으로 구성된 목록 헤더 |
| **내용 행** | 폴더 또는 파일 1건을 표시하는 행. 폴더/파일 여부에 따라 표시되는 값이 다르다 |
| **케밥 메뉴** | 내용 행 우측의 `⋮` 버튼과 그 하위 메뉴. 폴더는 이름 변경/이동/삭제, 파일은 상세 보기/미리보기 열기/다운로드/이름 변경/이동/삭제 |
| **새로만들기 컨테이너** | 상단 `새로 만들기` 버튼 클릭 시 나타나는, 새 폴더/Google Docs/Google Sheets/Google Slides/파일 업로드 선택 영역 |
| **새 폴더 만들기 모달** | 새 폴더 클릭 시 나타나는, 현재 위치와 폴더 이름을 입력하는 모달 |
| **Docs/Sheets/Slides 만들기 모달** | Google Docs/Sheets/Slides 클릭 시 나타나는, 파일 이름을 입력하는 모달 |
| **새 탭에서 열기 모달** | Docs/Sheets/Slides 생성 완료 후 나타나는, 새 탭에서 해당 파일을 열지 안내하는 모달 |
| **이름 변경 모달** | 폴더 또는 파일의 이름을 바꾸는 모달. 입력창에 현재 이름이 채워진 상태로 열린다 |
| **이동 모달** | 폴더 또는 파일을 다른 폴더로 옮기는 모달. 전체 폴더를 들여쓰기로 계층 표시하며, 대상을 클릭해 선택한다 |
| **삭제 확인 모달** | 폴더 또는 파일 삭제 전 확인하는 모달. 삭제 대상 이름·종류, 하위 항목 개수(있는 경우), 안내 문구가 함께 나타난다 |

## 3. 화면 구성

```
┌─ 공유폴더 화면 ──────────────────────────────────────────┐
│ [검색바]              [필터]         [새로 만들기]        │
├───────────────────────────────────────────────────────────┤
│ [저장소 컨테이너]                                         │
│  공유파일 루트 / 폴더A / 폴더B                            │  ← 각 구간 클릭 시 이동
│ ───────────────────────────────────────────────────────── │
│  이름          | 종류        | 수정자 | 수정일  | 크기 | ⋮ │
│  📁 폴더 이름  | 폴더        | 김서준 | 08.01   | -    | ⋮ │
│  📄 문서 이름  | Google Docs | 정다은 | 07.30   | -    | ⋮ │
│  📄 업로드 파일| 파일        | 정다은 | 07.29   | 2.3MB| ⋮ │
└───────────────────────────────────────────────────────────┘
```

- 현재 폴더에 항목이 하나도 없으면 "이 폴더에 파일이 없습니다." 안내와 함께 파일 업로드/폴더 만들기 버튼을 보여준다.
- 현재 폴더에 항목은 있지만 필터·검색 조건에 맞는 항목이 없으면 "파일이 없습니다." 문구만 보여준다(버튼 없음).

### 내용 행 — 폴더

폴더 아이콘, 폴더 제목(버튼 — 클릭하면 해당 폴더로 진입), 종류(고정값 "폴더"), 수정자 이름, 수정일 날짜, 크기(없으면 "-"), 케밥 메뉴로 구성된다.

### 내용 행 — 파일

종류별 아이콘, 파일 제목(텍스트, 아직 클릭 이벤트 없음), 종류(Google Docs/Google Sheets/Google Slides/업로드 파일 종류에 따라 표시), 수정자 이름, 수정일 날짜, 크기(없거나 알 수 없으면 "-"), 케밥 메뉴로 구성된다.

## 4. 기능 목록

### 4.1 필터 · 검색

| 기능 | 트리거 | 동작 | 상태 |
|---|---|---|---|
| 필터 전환 | 상단 전체/폴더/파일 탭 클릭 | 현재 폴더의 목록을 클릭한 종류로 걸러 보여줌 | 구현 완료 |
| 파일명 검색 | 검색바 입력 | 입력한 문자열을 포함하는 **파일**만 결과에 남김. 검색어가 있으면 폴더는 결과에서 제외된다 | 구현 완료 |

> 필터가 "폴더"인 상태에서 검색어를 입력하면 항상 결과가 없다 — 검색은 파일에만 적용되기 때문이다.

### 4.2 저장소 탐색

| 기능 | 트리거 | 동작 | 상태 |
|---|---|---|---|
| 폴더 진입 | 내용 행의 폴더 이름 클릭 | 해당 폴더로 이동, 파일경로·필터·검색어 초기화 | 구현 완료 |
| 경로 이동(breadcrumb) | 파일경로의 "공유파일 루트" 또는 상위 폴더명 클릭 | 클릭한 경로로 이동, 필터·검색어 초기화 | 구현 완료 |
| 파일 미리보기 | 내용 행의 파일 이름 클릭 | 미리보기 가능한 새 탭으로 이동 | 미구현 — 파일 이름은 클릭 이벤트가 없는 텍스트다 |
| 빈 폴더 안내(실제로 항목 없음) | 현재 폴더에 항목이 0건 | "이 폴더에 파일이 없습니다." 문구 + 파일 업로드/폴더 만들기 버튼 표시 | 구현 완료 |
| 결과 없음 안내(필터·검색으로 인함) | 항목은 있으나 필터·검색 결과가 0건 | "파일이 없습니다." 문구만 표시 | 구현 완료 |

### 4.3 새로 만들기

| 기능 | 트리거 | 동작 | 상태 |
|---|---|---|---|
| 새로만들기 컨테이너 열기/닫기 | 상단 `새로 만들기` 버튼 클릭 / 바깥 클릭 | 새 폴더/Google Docs/Google Sheets/Google Slides/파일 업로드 선택 영역 표시/닫힘 | 구현 완료 |
| 새 폴더 만들기 모달 열기/닫기 | 컨테이너에서 `새 폴더` 클릭 / 취소·바깥 클릭 | 현재 위치·폴더 이름 입력 모달 표시/닫힘 | 구현 완료 |
| 새 폴더 생성 | 모달 `만들기` 클릭(이름 미입력 시 버튼 비활성) | 현재 경로에 폴더 생성, 생성된 폴더로 즉시 이동하며 필터·검색어 초기화 | 구현 완료 |
| Docs/Sheets/Slides 만들기 모달 열기/닫기 | 컨테이너에서 `Google Docs`/`Google Sheets`/`Google Slides` 클릭 / 취소·바깥 클릭 | 입력창 모달(제목이 선택한 종류에 맞춰 바뀜) 표시/닫힘 | 구현 완료 |
| Docs/Sheets/Slides 생성 | 모달 `만들기` 클릭 | 입력한 이름(비어 있으면 종류별 기본 이름)으로 현재 경로에 파일 생성 후 새 탭에서 열기 모달 표시 | 구현 완료 |

| 파일 업로드 | 컨테이너에서 `파일 업로드` 클릭 → 네이티브 파일 선택 창에서 파일 선택 | 선택한 파일을 실제 파일명·크기(B/KB/MB)로 현재 경로에 추가 | 구현 완료 |

## 5. 데이터

### 폴더/파일 공통 항목

| 항목 | 설명 |
|---|---|
| 아이디 | 목록 내 고유 id. 새로 생성된 항목은 "생성 시점 기준 가장 큰 id + 1"부터 순서대로 부여된다 |
| 상위 폴더 id | 이 항목이 속한 폴더의 id. 공유파일 루트에 있으면 `null` |
| 이름 | 폴더/파일 제목 |
| 종류 | 폴더는 고정값, 파일은 Google Docs/Google Sheets/Google Slides/업로드 파일 중 하나 |
| 수정자 | 마지막으로 수정한 사용자 이름. 로그인 연동이 없어 항상 "김서준"으로 기록된다 |
| 수정일 | 마지막 수정 날짜. 생성·이름변경·이동 시 현재 시각으로 갱신된다 |
| 크기 | 폴더/파일 크기. 없거나 알 수 없으면 "-", 업로드 파일은 실제 크기를 B/KB/MB로 표시 |

### 경로

| 항목 | 설명 |
|---|---|
| 현재 경로 | 현재 위치한 폴더의 id(루트는 `null`)로 관리한다. 상위 폴더 id를 거슬러 올라가며 breadcrumb에 표시할 폴더 목록을 계산한다 |

## 6. 컴포넌트 구성

`src/feature/shared-folder/components/`에 실제로 존재하는 컴포넌트 기준. 아직 API 연동이 없어 `SharedFolderBoard`가 mock 데이터를 state로 들고 모든 조작을 로컬에서 처리한다.

| 컴포넌트 | 책임 |
|---|---|
| **SharedFolderBoard** | 화면 최상위 컴포넌트(client). 목록(`items`), 현재 경로(`currentFolderId`), 필터·검색어, 새로만들기·케밥 메뉴 열림 상태, 각 모달(새 폴더/Google/새 탭/이름변경/이동/삭제)의 열림 상태를 전부 소유한다. 생성·이름변경·이동·삭제 핸들러와 하위 항목 id를 재귀로 모으는 `getDescendantIds`도 이 컴포넌트에 있다. 바깥 클릭 시 새로만들기 컨테이너·케밥 메뉴를 닫으며, 숨겨진 `input[type=file]`도 여기서 관리한다 |
| **SharedFolderToolbar** | 상단 검색바·필터 탭·새로 만들기 버튼(client). 검색어·필터 변경을 그대로 부모에 전달하고, 새로만들기 컨테이너에서 `파일 업로드`를 선택하면 부모의 파일 선택창을 연다 |
| **SharedFolderCreateMenu** | `새로 만들기` 클릭 시 나타나는 컨테이너. 선택한 옵션(`FOLDER`/`GOOGLE_DOCS`/`GOOGLE_SHEETS`/`GOOGLE_SLIDES`/`UPLOAD`)을 그대로 상위에 전달한다 |
| **SharedFolderCreateNewFolderModal** | 새 폴더 이름 입력 모달. 현재 위치를 안내하고, 이름이 비어 있으면 `만들기` 버튼이 비활성화된다 |
| **SharedFolderCreateGoogleModal** | Docs/Sheets/Slides 파일 이름 입력 모달. `fileType`에 따라 제목이 바뀌고, 이름이 비어 있으면 종류별 기본 이름("제목 없는 문서" 등)으로 생성한다. `SharedFolderItem`의 `FILE_TYPE_LABEL`을 재사용한다 |
| **SharedFolderOpenNewTabModal** | Google 파일 생성 완료 후 나타나는 모달. 실제 새 탭 열기는 없고 닫기만 한다 |
| **SharedFolderPath** | 폴더 경로(breadcrumb, client). "공유파일 루트"와 현재 경로의 폴더들을 클릭하면 그 경로로 이동한다 |
| **SharedFolderListHeader** | 이름·종류·수정자·수정일·크기 제목행 |
| **SharedFolderList** | 현재 폴더의 항목 목록을 `SharedFolderItem`으로 매핑한다. 폴더 자체가 비어 있으면(`isFolderEmpty`) 안내 문구 + 업로드/폴더 만들기 버튼을, 필터·검색 때문에 결과만 없으면 "파일이 없습니다." 문구만 보여준다 |
| **SharedFolderItem** | 폴더/파일 내용 행 1건. 폴더는 이름이 버튼으로 렌더링되어 클릭 시 그 폴더로 진입하고, 파일 이름은 아직 클릭 이벤트가 없다. 케밥 버튼 클릭 시 `SharedFolderItemMenu`를 연다. 종류별 표시 라벨(`FILE_TYPE_LABEL`)을 export해 `SharedFolderCreateGoogleModal`과 공유한다 |
| **SharedFolderItemMenu** | 케밥 메뉴 내용. `kind`가 `FILE`이면 상세 보기/미리보기 열기/다운로드 항목이 추가되지만 클릭하면 메뉴만 닫힌다. 이름 변경/이동/삭제는 폴더·파일 모두 실제 모달로 이어진다 |
| **SharedFolderEditNameModal** | 이름 변경 모달. 현재 이름으로 입력창이 채워지고, 값이 비어 있으면 `변경` 버튼이 비활성화된다 |
| **SharedFolderMoveModal** | 이동 모달. 전체 폴더를 들여쓰기로 계층 표시하며, 이동 대상(자기 자신·하위 폴더 제외)을 클릭해 선택한다. 현재 위치와 같은 대상을 선택한 상태면 `이동` 버튼이 비활성화된다 |
| **SharedFolderDeleteCheckModal** | 삭제 확인 모달. 대상 이름·종류, 하위 항목 개수(있는 경우), "Google Drive 휴지통으로 이동" 안내 문구를 보여준다 |

### 관계

```
SharedFolderBoard                       (items, currentFolderId, filter, searchQuery, 각종 열림 state)
├── SharedFolderToolbar
│   └── SharedFolderCreateMenu          (새로 만들기 클릭 시)
├── (저장소 컨테이너 — Board가 직접 마크업)
│   ├── SharedFolderPath
│   ├── SharedFolderListHeader
│   └── SharedFolderList
│       └── SharedFolderItem[]
│           └── SharedFolderItemMenu    (케밥 클릭 시)
├── input[type=file]                    (파일 업로드, 숨김)
├── SharedFolderCreateNewFolderModal    (새 폴더 선택 시)
├── SharedFolderCreateGoogleModal       (Google Docs/Sheets/Slides 선택 시)
├── SharedFolderOpenNewTabModal         (Google 파일 생성 완료 시)
├── SharedFolderEditNameModal           (이름 변경 선택 시)
├── SharedFolderMoveModal               (이동 선택 시)
└── SharedFolderDeleteCheckModal        (삭제 선택 시)
```

### 컴포넌트 외 필요한 조각

| 조각 | 역할 | 상태 |
|---|---|---|
| 폴더/파일 목록 데이터 | Google Drive 연동 조회 | 미구현 — `SharedFolderBoard`의 in-memory state(mock 배열로 초기화)로 대신하며, 새로고침하면 초기화된다 |
| 파일 상세보기/미리보기/다운로드 | 케밥 메뉴의 해당 항목, 파일 이름 클릭 | 미구현 |
| 새 탭에서 열기 | Google 파일 생성 완료 모달의 실행 버튼 | 미구현 — 모달을 닫기만 한다 |
| 로그인 사용자 연동 | 수정자 표시, 권한 판별 | 미구현 — 모든 생성·수정이 "김서준"으로 고정 기록된다 |
| Sidebar 진입점 | 공유폴더 메뉴 항목 | 미구현 |
