# Timetable(시간표) Domain — CONTEXT
> 배치 경로: `src/feature/timetable/CONTEXT.md`
> 목적: 이 문서를 읽은 사람 또는 AI 에이전트가 시간표 도메인이 **무엇을 하는 도메인이고, 어떤 기능이 있으며, 어떤 조각으로 이루어져 있는지** 파악할 수 있게 한다.
> 구현 상태: 현재는 `src/app/(user)/timetable/page.tsx`에 더미 데이터 기반의 정적 UI(상단 바 + 중간 필터 + 주간 시간표 그리드)만 존재한다. 템플릿 선택, 수업 등록/관리 모달, 새 시간표 생성 마법사, 내보내기, 필터 동작, API 연동은 전부 미구현이다. `src/feature/timetable/` 하위에는 아직 컴포넌트·타입·서비스 파일이 없다.

---

## 1. 개요

학원에서 하나 이상의 **시간표 템플릿**을 만들고, 템플릿마다 요일·강의실 단위로 수업을 등록해 주간 단위로 조회하는 도메인.

시간표 템플릿은 기간(시작일~종료일)을 가지는 독립된 단위로, 학원은 여러 템플릿을 만들어두고 그중 하나를 선택해 화면에 띄운다. 템플릿은 운영 요일·운영 시간·슬롯 단위(시간표를 몇 분 단위로 나눌지)와 강의실 배치(층/호수)를 함께 정의하며, 이 설정이 그 템플릿에 등록되는 수업의 시간표 그리드 형태를 결정한다.

### 핵심 제약

- 화면에 보이는 주간 날짜는 **선택된 템플릿을 만들 때 지정한 시작일을 기준**으로 이동한다. `<`/`>` 버튼은 이 기준일에서 1주 단위로 앞뒤로 이동한다.
- 템플릿 상태(진행 중 / 예정 / 종료)는 템플릿의 시작일·종료일과 현재 날짜를 비교해 결정되는 파생 값이다.
- 수업 등록 시 종료 시각은 시작 시각보다 빠를 수 없고, 새 시간표 생성 1단계에서도 종료일은 시작일보다 빠를 수 없다.
- 새 시간표 생성은 **기본정보 → 템플릿 설정 → 강의실 설정** 3단계 마법사이며, 각 단계를 통과해야 다음 단계로 진행할 수 있다(기본정보의 모든 값 입력 전에는 다음 버튼 비활성).
- 강의실 설정의 기본값은 1층~5층까지 각 층에 1개씩(`1층 101호`, `2층 201호` … `5층 501호`)이며, "이전 세팅 불러오기"를 선택하면 이 기본값 대신 이전 템플릿의 층/강의실 구성이 채워진다.

### 진입점

Sidebar의 시간표 메뉴(라우트 `src/app/(user)/timetable/page.tsx`).

### 데이터 연동 계층

미구현. 현재 `page.tsx` 안에 임시 타입(`ClassItem`)과 더미 데이터(`days`, `classItems`, `times`, `classTone`)가 직접 선언되어 있으며, 추후 API 연동 시 삭제될 예정으로 주석이 달려 있다. `src/feature/timetable/type.ts` / `actions.ts` / `src/service/timetable.service.ts`는 아직 없다.

## 2. 용어

| 용어 | 정의 |
|---|---|
| **시간표 템플릿** | 기간·운영 요일/시간·슬롯 단위·강의실 배치를 가지는 시간표 단위. 상단 select로 전환한다 |
| **진행 중 / 예정 / 종료** | 템플릿의 현재 상태. 진행 중인 템플릿은 목록에서 색상이 다르게 표시된다 |
| **주 단위 날짜 조정** | 상단 `<`/`>` 버튼으로 1주 단위로 조회 주간을 이동하는 기능 |
| **수업 등록 모달** | 요일·강의실·시작/종료 시각·학년·강사·과목을 입력해 시간표에 수업 1건을 등록하는 모달 |
| **시간표 관리 모달** | 기존 템플릿 목록을 제목/날짜/등록된 수업/상태로 보여주고 수정·삭제·새 시간표 생성으로 진입하는 모달 |
| **새 시간표 생성 마법사** | 1 기본정보 → 2 템플릿 설정 → 3 강의실 설정 순으로 진행하는 템플릿 생성/수정 모달 |
| **슬롯 단위** | 시간표 그리드에서 시간을 나누는 단위(10분/30분/60분). 템플릿 기본정보에서 설정 |
| **층 설정** | 강의실 설정 단계에서 층을 추가하고 각 층에 강의실(호수)을 추가하는 좌측 영역 |
| **미리보기** | 강의실 설정 단계 우측에서 현재까지 설정한 층·호수 구성을 확인하는 영역 |

## 3. 화면 구성

시간표 페이지는 **상단(템플릿/주간 이동/액션 버튼) → 중간(필터) → 시간표(주간 그리드)** 3단으로 구성된다.

```
┌─ 시간표 페이지 ────────────────────────────────────────────────┐
│ [상단]                                                          │
│  [템플릿 선택 ▾]  [<] 08.03 ~ 08.09 [>]   [수업 등록][내보내기][시간표 관리] │
├──────────────────────────────────────────────────────────────────┤
│ [중간]                                                          │
│  [요일 선택 ▾] [전체 층 ▾]                    [🔍 강사 검색]     │
├──────────────────────────────────────────────────────────────────┤
│ [시간표]                                                        │
│        일          월          화          화          …        │
│        08.03       08.04       08.05                            │
│        601 602 …   601 602 …   501 502 …                        │
│ 08:00  ┌────┐                                                    │
│ 09:00  │수업│                                                    │
│  …     └────┘                                                    │
│ 22:00                                                            │
└──────────────────────────────────────────────────────────────────┘
```

### 상단

| 요소 | 설명 |
|---|---|
| 시간표 템플릿 선택 | select 형식. 클릭하면 템플릿 목록(제목/상태/날짜, 최하단 새 시간표 만들기)이 나타남 |
| 주 단위 날짜 조정 | `<`/`>` 버튼으로 1주 단위 이동. 기준일은 선택된 템플릿의 생성 시 시작일 |
| 수업 등록 버튼 | 수업 등록 모달 오픈 |
| 내보내기 버튼 | 클릭 시 버튼 아래에 엑셀(.xlsx)/PDF/이미지(PNG) 다운로드 옵션 컨테이너 노출 |
| 시간표 관리 버튼 | 시간표 관리 모달 오픈 |

### 중간

| 요소 | 설명 |
|---|---|
| 요일 선택 | select. 월~일 중 선택 |
| 전체 층 | select. 전체 또는 특정 층으로 시간표 표시 범위를 좁힘 |
| 시간표 검색 | 강사 이름 등으로 검색 |

### 시간표(주간 그리드)

- 최상단에 요일·날짜, 그 아래 강의실 호수, 그 아래 08:00~22:00 시간축이 나타난다.
- 각 강의실·시간 칸에 해당 시간에 등록된 수업이 표시된다.

## 4. 기능 목록

### 4.1 시간표 템플릿 선택 — 미구현

| 기능 | 트리거 | 동작 |
|---|---|---|
| 템플릿 목록 열기 | 상단 템플릿 select 클릭 | 제목·상태·날짜를 가진 템플릿 목록이 아래로 펼쳐짐 |
| 상태 표시 | 목록의 각 템플릿 | 진행 중(색상 변경 강조) / 예정 / 종료 상태 문구 표시 |
| 템플릿 전환 | 목록에서 템플릿 클릭 | 선택한 템플릿의 시간표로 화면 전환, 주간 기준일도 해당 템플릿 시작일로 갱신 |
| 새 시간표 만들기 진입 | 템플릿 목록 최하단 `새 시간표 만들기` 클릭 | 새 시간표 생성 마법사(1 기본정보)로 이동 |

| 엑셀 다운로드 | 옵션에서 `엑셀(.xlsx)` 클릭 | 현재 시간표를 .xlsx로 다운로드 |

| 이미지 다운로드 | 옵션에서 `이미지(PNG)` 클릭 | 현재 시간표를 PNG로 다운로드 |

### 4.5 시간표 관리 — 미구현

| 기능 | 트리거 | 동작 |
|---|---|---|
| 관리 모달 열기 | 상단 `시간표 관리` 클릭 | 시간표 제목·날짜·등록된 수업·상태 목록과 최하단 `새 시간표` 버튼이 있는 모달 노출 |
| 항목 메뉴 열기 | 목록 항목의 `...` 버튼 클릭 | 수정/삭제 옵션 컨테이너 노출 |
| 수정 | `...` 메뉴에서 `수정` 클릭 | 해당 템플릿 값이 채워진 상태로 시간표 등록(생성 마법사) 모달이 열림 |
| 삭제 | `...` 메뉴에서 `삭제` 클릭 | 해당 템플릿 삭제 |
| 새 시간표 생성 진입 | 모달 최하단 `새 시간표` 클릭 | 새 시간표 생성 마법사(1 기본정보)로 이동 |

### 4.6 새 시간표 생성 — 미구현

3단계 마법사로 진행되며 상단에 `1 기본정보 / 2 템플릿 설정 / 3 강의실 설정`이 표시되고 현재 단계에 맞는 숫자가 활성화된다.

| 기능 | 트리거 | 동작 |
|---|---|---|
| 시간표 이름 입력 | 1단계 입력란 | 템플릿 이름 입력 |
| 시작일/종료일 선택 | 1단계 날짜 선택 | 종료일은 시작일보다 빠를 수 없음 |
| 운영 시작 시각 선택 | 1단계 select | 08:00~21:00 중 선택 |
| 운영 종료 시각 선택 | 1단계 select | 09:00~22:00 중 선택 |
| 운영 요일 선택 | 1단계 select | 월요일~일요일 중 선택 |
| 슬롯 단위 선택 | 1단계 select | 10분/30분/60분 중 선택. 선택한 값에 따라 시간표 그리드의 시간 분할 단위가 달라짐 |
| 1단계 다음 | 모든 값 입력 완료 | `다음` 버튼이 활성화되고 클릭 시 2단계(템플릿 설정)로 이동 |
| 이전 세팅 불러오기 | 2단계 `이전 세팅 불러오기` 클릭 후 다음 | 3단계 강의실 설정이 이전 템플릿의 값으로 채워진 상태로 진입 |
| 새 강의실 설정 | 2단계 `새 강의실 설정` 클릭 후 다음 | 3단계 강의실 설정이 기본값(1층 101호~5층 501호)으로 진입 |
| 층 추가 | 3단계 좌측 `층 추가` 클릭 | 새로운 층이 좌측 층 설정 목록에 추가됨 |
| 강의실 추가 | 각 층의 `+ 추가` 클릭 | 해당 층에 강의실(호수)이 추가됨 |
| 미리보기 확인 | 3단계 우측 | 좌측에서 설정한 층·호수 구성이 그대로 표시됨 |
| 생성 완료 | 3단계 `완료` 클릭 | 시간표 템플릿이 생성됨 |

### 4.7 중간 필터 — 미구현(정적 UI만 존재)

| 기능 | 트리거 | 동작 |

### 4.8 주간 시간표 그리드 — 정적 UI 구현(더미 데이터)

| 기능 | 트리거 | 동작 |
|---|---|---|
| 요일/날짜 헤더 표시 | 페이지 진입 | 조회 중인 주간의 요일·날짜를 그리드 최상단에 표시 |
| 강의실 헤더 표시 | 페이지 진입 | 요일별로 배정된 강의실 호수를 요일 헤더 바로 아래에 표시 |

## 5. 데이터

현재 `page.tsx`에 선언된 임시 타입·더미 데이터 기준(추후 API 연동 시 대체될 예정).

### 요일 (`days`)

| 항목 | 설명 |
|---|---|
| `name` | 요일 이름(일~토) |
| `date` | 해당 요일의 날짜(`MM.dd`) |
| `rooms` | 그 요일에 표시되는 강의실 호수 목록 |

### 수업 (`ClassItem`)

| 항목 | 설명 |
|---|---|
| `day` | `days` 배열 인덱스로 요일을 가리킴 |
| `room` | 해당 요일 `rooms` 배열 인덱스 |
| `start` | 시간표 그리드에서의 시작 행(30분 단위 슬롯 기준) |
| `duration` | 소요 슬롯 수 |
| `course` | 표시할 과목/학년 텍스트 |
| `teacher` | 강사 이름 |
| `tone` | 카드 색상(`blue`/`green`/`stone`/`sky`) |

### 시간축 (`times`)

08:00부터 22:00까지 1시간 단위 문자열 배열.

## 6. 컴포넌트 구성

`src/feature/timetable/` 하위에 아직 컴포넌트가 없다. 현재 시간표 화면 전체(상단 바, 중간 필터, 주간 그리드)가 `src/app/(user)/timetable/page.tsx` 하나에 서버 컴포넌트로 작성되어 있으며, 셀렉트·버튼 등에 클릭 핸들러나 상태가 연결되어 있지 않다(마크업만 존재).

### 앞으로 필요한 조각(미구현)

| 조각 | 역할 |
|---|---|
| 템플릿 선택 드롭다운 | 템플릿 목록 조회, 선택한 템플릿으로 화면 전환 |
| 주간 이동 상태 | 선택된 템플릿의 시작일을 기준으로 조회 주간을 계산·이동 |
| 수업 등록 모달 | 요일·강의실·시간·학년·강사·과목 입력 및 등록 |
| 내보내기 | 엑셀/PDF/이미지 생성 및 다운로드 |
| 시간표 관리 모달 | 템플릿 목록 조회, 수정/삭제, 새 시간표 생성 진입 |
| 새 시간표 생성 마법사 | 기본정보 → 템플릿 설정 → 강의실 설정 3단계 상태 관리 |
| 강의실 설정(층/호수) | 층·강의실 추가 및 미리보기 동기화 |
| 요일/층/강사 필터 | 시간표 그리드에 표시할 범위 필터링 |
| 시간표 데이터 연동 | 템플릿·수업 조회 및 CRUD API 연동(`type.ts`/`actions.ts`/`timetable.service.ts`) |
