# Corporate Card(법인카드) Domain — CONTEXT
> 배치 경로: `src/feature/corporate-card/CONTEXT.md`
> 목적: 이 문서를 읽은 사람 또는 AI 에이전트가 법인카드 도메인이 **무엇을 하는 도메인이고, 어떤 기능이 있으며, 어떤 조각으로 이루어져 있는지** 파악할 수 있게 한다.
> 구현 상태: 라우팅 골격(레이아웃·탭 이동)만 구현되어 있다. 법인카드 탭 화면 구성 요소·API 연동은 아직 없다.

---

## 1. 개요

사용자가 자신의 법인카드 사용 내역을 조회하고, 각 내역에 사용목적·사용사유를 작성해 결재를 상신하는 도메인.

재무(Finance) 페이지는 법인카드 탭과 급여명세서 탭으로 구성되며, 재무 페이지에 진입하면 기본으로 법인카드 탭이 열린다. 이 도메인은 그중 법인카드 탭을 다룬다.

### 핵심 제약

- 법인카드 내역 1건은 UNWRITTEN(미작성) / IN_PROGRESS(진행중) / APPROVED(승인됨) / REJECTED(반려됨) 중 하나의 결재 상태를 가진다.
- 결재 상신은 목록에서 여러 건을 체크한 뒤 상단 `결제 상신` 버튼을 눌러 일괄로 진행한다.
- 결재선(승인자 지정)을 지정하지 않고 결재 상신을 시도하면, 먼저 결재선을 지정하라는 안내가 나타나 상신이 진행되지 않는다.
- 최초로 결재선을 지정해 상신에 성공하면, 그 결재선이 이후 상신에 재사용되는 템플릿이 된다.

### 진입점 및 라우팅

- Sidebar의 재무 메뉴(`src/components/layout/Sidebar.tsx`, `href: "/finance"`).
- `src/app/(user)/finance/layout.tsx`가 헤더(탭 네비게이션 `FinanceTabs`, 민감정보 안내)를 공통으로 렌더링하고 `{children}`으로 선택된 탭의 라우트를 표시한다. 탭 이동은 라우트 전환(`/finance/corporate-card`, `/finance/payroll`)으로 이루어지며, 이 레이아웃은 라우트가 바뀌어도 리마운트되지 않는다.
- `src/app/(user)/finance/page.tsx`: `/finance/corporate-card`로 `redirect`한다(급여명세서를 기본 탭으로 바꿀 이유가 없는 한 법인카드가 기본 탭).
- `src/app/(user)/finance/corporate-card/page.tsx`: 법인카드 탭 라우트. 아직 자리만 잡아둔 상태이며 실제 화면 구성 요소는 이 도메인 작업이 진행되며 채워진다.
- 급여명세서 탭(`/finance/payroll`)은 별도 도메인으로, 아직 라우트가 만들어지지 않아 `FinanceTabs`에서 링크가 아닌 비활성 표시로만 노출된다.

## 2. 용어

| 용어 | 정의 |
|---|---|
| **재무 페이지** | 법인카드 탭과 급여명세서 탭으로 구성된 페이지. Sidebar의 재무 클릭으로 진입 |
| **법인카드 탭** | 재무 페이지 진입 시 기본으로 열리는 탭. 법인카드 내역 조회·결재 상신을 다룸 |
| **이번 달 법인카드 정보 컨테이너** | 이번 달 사용액·사용 건수·사용목록 미작성 건수·결제 진행 현황(대기/결재중/승인/반려)을 요약해 보여주는 영역 |
| **법인카드 내역 컨테이너** | 개별 법인카드 사용 내역을 행 단위로 나열하는 목록 영역 |
| **사용내역 상세 컨테이너** | 목록에서 보기/작성 버튼을 눌렀을 때 우측에 나타나는, 내역 1건의 상세·사용목적·결재 정보를 다루는 영역 |
| **사용내역 컨테이너** | 사용내역 상세 컨테이너 안에서 가게이름·승인일시·카드·승인번호·가맹점·할부·금액 등 원 결제 정보를 보여주는 영역 |
| **사용목적 컨테이너** | 사용내역 상세 컨테이너 안에서 선택된 사용목적과 작성한 사용 사유를 보여주는 영역(승인됨/진행중 상태, 조회 전용) |
| **사용목적 작성 컨테이너** | 사용내역 상세 컨테이너 안에서 사용목적·사용사유·결재선을 입력하는 영역(미작성/반려됨 상태, 입력 가능) |
| **결재 현황 컨테이너** | 지정된 결재자별 이름·직책·n차 승인 여부·승인시간을 보여주는 영역(승인됨/진행중 상태) |
| **결재선 지정** | 사용목적 작성 컨테이너 안에서 n차 승인자를 지정·추가하는 기능. 마지막 승인자가 최종 승인자가 된다 |
| **반려 사유 컨테이너** | 반려됨 상태에서 사용내역 상세 컨테이너 최상단에 나타나는, 반려 사유·반려자·반려일시와 임시저장/재상신 버튼을 담은 영역 |

## 3. 화면 구성

```
┌─ 법인카드 탭 ──────────────────────────────────────────────┐
│ [날짜 선택 캘린더] [이번달]              [결제 상신]        │
├──────────────────────────────────────────────────────────┤
│ [이번 달 법인카드 정보 컨테이너]                            │
│  이번 달 사용액   사용 건수   사용목록 미작성(작성하기)      │
│  결제 진행: 대기 / 결재중 / 승인 / 반려                     │
├──────────────────────────────────────────────────────────┤
│ [검색바]  [필터]                                            │
├──────────────────────────────────────────────────────────┤
│ [법인카드 내역 컨테이너]                                    │
│  ☐ 승인일시 | 가맹점 | 카드 | 금액/사용목적 | 결재 상태 | (버튼) │
│  ☐ 08.01   | OO식당 | 신한··1234 | 32,000원/식대 | 승인   | 보기 │
│  ☐ 08.02   | OO문구 | 국민··5678 | 15,000원/사무용품 | 미작성 | 작성 │
└──────────────────────────────────────────────────────────┘
```

- 상단에는 날짜 선택 캘린더, 이번달 버튼, 결제 상신 버튼이 위치한다.
- 목록 최상단 행(헤더)의 체크표시를 클릭하면 목록의 모든 행이 체크된다.
- 체크된 행이 있는 상태에서 `결제 상신`을 클릭하면 체크된 내역들이 결재 상신된다.
- 각 행 마지막 열은 값을 표시하지 않지만 버튼을 위한 공간을 차지한다. 승인/결재중/대기 상태에서는 `보기` 버튼, 미작성 상태에서는 `작성` 버튼이 나타난다.

### 법인카드 내역 컨테이너 — 행 구성

| 열 | 표시 내용 |
|---|---|
| 체크표시 + 승인일시 | 체크박스와 승인 날짜 |
| 가맹점 | 가맹점 이름, 가맹점 종류(일반음식점/소매/주유소 등) |
| 카드 | 카드 이름, 카드 뒷자리 번호 |
| 금액/사용목적 | 결제 금액, 사용목적 |
| 결재 상태 | 승인 / 결재중 / 미작성 / 반려 / 대기 |
| (버튼 영역) | 승인·결재중·대기 상태: `보기` 버튼 / 미작성 상태: `작성` 버튼 |

### 사용내역 상세 컨테이너 — 승인됨 / 진행중 상태

`보기`를 클릭하면 우측에 나타난다. 사용내역 컨테이너, 사용목적 컨테이너, 결재 현황 컨테이너 순으로 구성된다.

```
┌─ 사용내역 상세 컨테이너 (승인/진행중) ─┐
│ [사용내역 컨테이너]                    │
│  가게이름  승인일시(승인날짜)          │
│  카드(카드이름·카드번호)               │
│  승인번호  가맹점(가게종류)            │
│  할부(일시불/개월)  금액               │
├────────────────────────────────────────┤
│ [사용목적 컨테이너]                    │
│  선택한 사용목적                       │
│  작성한 사용 사유                      │
├────────────────────────────────────────┤
│ [결재 현황 컨테이너]                   │
│  결재자 이름·직책·n차 승인·승인시간    │
└────────────────────────────────────────┘
```

### 사용내역 상세 컨테이너 — 반려됨 상태

반려 사유 컨테이너, 사용내역 컨테이너, 사용목적 작성 컨테이너 순으로 구성된다.

```
┌─ 사용내역 상세 컨테이너 (반려) ────────┐
│ [반려 사유 컨테이너]                   │
│  반려 사유  반려자  반려일시           │
│  [임시저장]  [재상신]                  │
├────────────────────────────────────────┤
│ [사용내역 컨테이너]                    │
│  가게이름  승인일시(승인날짜)          │
│  카드(카드이름·카드번호)               │
│  승인번호  가맹점(가게종류)            │
│  할부(일시불/개월)  금액               │
├────────────────────────────────────────┤
│ [사용목적 작성 컨테이너]               │
│  사용 목적(선택)  사용 사유(입력)      │
│  결재선 지정(승인자 지정/추가)         │
└────────────────────────────────────────┘
```

### 사용내역 상세 컨테이너 — 미작성 상태

반려 사유 컨테이너를 제외하면 반려됨 상태와 동일한 구성이다(사용내역 컨테이너 + 사용목적 작성 컨테이너). 반려됨 상태의 `재상신` 버튼 자리는 `결재 상신` 버튼으로 나타난다.

### 사용목적 작성 컨테이너 — 세부

| 요소 | 설명 |
|---|---|
| 사용 목적 | 식대 / 도서·교재 / 사무용품 / 교통비 / 시설·비품 / 교육비 / 기타 중 선택 |
| 사용 사유 | 자유 입력 텍스트 |
| 결재선 지정 | n차 승인자 지정·추가. 마지막 승인자는 최종 승인자로 표시됨 |

## 4. 기능 목록

### 4.1 법인카드 탭 진입

| 기능 | 트리거 | 동작 | 상태 |
|---|---|---|---|
| 재무 페이지 진입 | Sidebar `재무` 클릭 | 법인카드 탭이 기본 선택된 재무 페이지로 이동 | 미구현 |
| 법인카드/급여명세서 탭 전환 | 재무 페이지 상단 탭 클릭 | 선택한 탭 내용으로 전환 | 미구현 |

### 4.2 이번 달 법인카드 정보

| 기능 | 트리거 | 동작 | 상태 |
|---|---|---|---|
| 이번 달 요약 조회 | 법인카드 탭 진입 | 이번 달 사용액, 사용 건수, 사용목록 미작성 건수, 결제 진행 현황(대기/결재중/승인/반려)을 표시 | 미구현 |
| 사용목록 작성 진입 | 정보 컨테이너의 `작성하기` 클릭 | 미작성 내역 작성으로 이동(4.5 참고) | 미구현 |

### 4.3 날짜 선택 / 검색 / 필터

| 기능 | 트리거 | 동작 | 상태 |
|---|---|---|---|
| 날짜 선택 | 상단 캘린더 클릭 | 선택한 날짜(구간) 기준으로 법인카드 내역 조회 | 미구현 |
| 이번달로 이동 | 상단 `이번달` 버튼 클릭 | 조회 기준을 이번 달로 초기화 | 미구현 |
| 내역 검색 | 검색바 입력 | 가맹점·카드 등 기준으로 내역 필터링 | 미구현 |
| 내역 필터 | 필터 선택 | 결재 상태 등 조건으로 내역 필터링 | 미구현 |

### 4.4 법인카드 내역 목록 / 결재 상신

| 기능 | 트리거 | 동작 | 상태 |
|---|---|---|---|
| 내역 전체 선택 | 목록 헤더 행의 체크표시 클릭 | 목록의 모든 행이 체크됨 | 미구현 |
| 내역 개별 선택 | 각 행의 체크표시 클릭 | 해당 행만 체크됨 | 미구현 |
| 결재 상신 | 하나 이상 체크 후 상단 `결제 상신` 클릭 | 체크된 내역이 결재 상신됨 | 미구현 |
| 결재선 미지정 안내 | 결재선이 지정되지 않은 내역이 포함된 상태로 결재 상신 시도 | 결재선을 먼저 지정해달라는 안내 표시, 상신 진행되지 않음 | 미구현 |
| 결재선 템플릿화 | 결재선을 지정하고 최초 상신에 성공 | 지정한 결재선이 템플릿으로 저장되어 이후 상신에 재사용됨 | 미구현 |
| 보기 진입 | 승인·결재중·대기 상태 행의 `보기` 클릭 | 우측에 사용내역 상세 컨테이너(승인/진행중 구성) 노출 | 미구현 |
| 작성 진입 | 미작성 상태 행의 `작성` 클릭 | 우측에 사용내역 상세 컨테이너(미작성 구성) 노출 | 미구현 |

### 4.5 사용목적 작성 / 결재선 지정

| 기능 | 트리거 | 동작 | 상태 |
|---|---|---|---|
| 사용 목적 선택 | 사용목적 작성 컨테이너의 목적 선택 | 식대/도서·교재/사무용품/교통비/시설·비품/교육비/기타 중 하나 선택 | 미구현 |
| 사용 사유 입력 | 사용 사유 입력란 작성 | 자유 텍스트 입력 | 미구현 |
| 승인자 지정 | 결재선 지정에서 승인자 추가 | n차 승인자로 추가되며, 마지막 승인자는 최종 승인자로 표시 | 미구현 |
| 임시저장 | 반려됨 상태에서 `임시저장` 클릭 | 작성 중인 내용 저장(상신하지 않음) | 미구현 |
| 재상신 | 반려됨 상태에서 `재상신` 클릭 | 결재 상신 진행 | 미구현 |
| 결재 상신(미작성) | 미작성 상태에서 `결재 상신` 클릭 | 결재 상신 진행 | 미구현 |

## 6. 컴포넌트 구성

기능 단위로 분해했을 때 필요한 컴포넌트 목록과 각자의 책임.

| 컴포넌트 | 책임 |
|---|---|
| **FinanceCardCalendar** | 날짜 선택 캘린더. 선택한 날짜(구간)를 상위로 전달해 목록 조회 기준을 결정한다 |
| **FinanceCardMonthOverview** | 이번 달 사용액·사용 건수·사용목록 미작성 건수·결제 진행 현황(대기/결재중/승인/반려)을 표시. 미작성 건수의 `작성하기` 클릭 시 해당 미작성 내역의 작성으로 연결한다 |
| **FinanceCardListFilter** | 검색바 + 필터. 입력/선택 값을 상위로 전달해 목록 조회 조건을 결정한다 |
| **FinanceCardList** | 법인카드 내역 목록 셸. 상위로부터 내역 목록과 체크된 항목 상태를 props로 받아 `FinanceCardListItem`을 렌더링하고, 헤더 행의 체크표시 클릭 시 전체 선택을 상위로 알린다(체크 상태 자체는 상위 셸이 소유 — 관계 참고) |
| **FinanceCardListItem** | 내역 1건의 행. 체크표시, 승인일시, 가맹점, 카드, 금액/사용목적, 결재 상태, 보기/작성 버튼을 표시하고 체크·보기·작성 클릭을 상위로 전달한다 |
| **FinanceCardDetail** | 우측 사용내역 상세 컨테이너 셸. 선택된 내역의 결재 상태를 보고 승인됨/진행중이면 사용내역·사용목적(읽기전용)·결재 현황을 직접 렌더링하고, 미작성/반려됨이면 `FinanceCardApprovalForm`을 마운트한다(반려됨 상태에서는 반려 사유 컨테이너도 함께 표시) |
| **FinanceCardApprovalForm** | 사용목적 작성 컨테이너. 사용목적 선택·사용 사유 입력·결재선 지정을 담당하며, 미작성 상태의 최초 작성과 반려됨 상태의 재상신에 공용으로 쓰인다. 결재선 미지정 상태로 상신을 시도하면 안내만 표시하고 진행하지 않으며, 결재선을 지정한 최초 상신이 성공하면 그 결재선이 템플릿으로 저장된다 |

> `이번달` 버튼과 `결제 상신` 버튼은 `FinanceCardCalendar`에 속하지 않고, 법인카드 탭 셸에서 캘린더·목록·상세와 형제로 배치되는 별도 버튼이다(전용 컴포넌트로 분리하지 않음).
> `FinanceCardApprovalForm`은 승인됨/진행중 상태(읽기전용)를 렌더링하지 않는다 — 그 경우는 `FinanceCardDetail`이 직접 그린다.

### 관계

```
법인카드 탭 (셸)                     (선택 날짜, 검색/필터 조건, 체크된 내역, 선택된 상세 항목 state)
├── FinanceCardCalendar             (날짜 선택)
├── (이번달 버튼)                    (조회 기준 초기화, 전용 컴포넌트 아님)
├── (결제 상신 버튼)                 (체크된 내역으로 결재 상신, 전용 컴포넌트 아님)
├── FinanceCardMonthOverview        (이번 달 요약)
├── FinanceCardListFilter           (검색/필터 입력)
├── FinanceCardList                 (내역 목록, 체크 상태는 셸의 state를 props로 전달받음)
│   └── FinanceCardListItem[]       (보기/작성 클릭 시 셸의 "선택된 상세 항목" state 갱신)
└── FinanceCardDetail               (선택된 상세 항목이 있을 때만 노출)
    └── FinanceCardApprovalForm     (미작성/반려됨 상태일 때만 마운트)
```

### 컴포넌트 외 필요한 조각

| 조각 | 역할 | 상태 |
|---|---|---|
| 선택된 날짜(구간) | 목록 조회 기준. 법인카드 탭 셸에서 관리하며 `FinanceCardCalendar`/`이번달` 버튼이 갱신 | 미구현 |
| 검색어/필터 조건 | 목록 조회 조건. 법인카드 탭 셸에서 관리하며 `FinanceCardListFilter`가 갱신 | 미구현 |
| 체크된 내역 상태 | 결재 상신 대상 목록. `FinanceCardList`/`ListItem` 내부가 아니라 법인카드 탭 셸에서 관리해 `결제 상신` 버튼과 공유 | 미구현 |
| 선택된 상세 항목 | 목록에서 보기/작성한 내역. 법인카드 탭 셸에서 관리하며 `FinanceCardDetail`의 노출 여부·내용을 결정 | 미구현 |
| 결재선 템플릿 | 결재선을 지정한 최초 상신이 성공하면 저장되는 결재선. 이후 `FinanceCardApprovalForm`의 기본값으로 재사용 | 미구현 |

## 7. 상태 정리

| 상태 | 값 |
|---|---|
| 재무 페이지 탭 | 법인카드 / 급여명세서 |
| 법인카드 내역 결재 상태 | UNWRITTEN(미작성) / IN_PROGRESS(진행중) / APPROVED(승인됨) / REJECTED(반려됨), 목록상 대기 포함 |
| 목록 행 체크 | 체크 안 됨 / 체크됨(개별 또는 전체) |
| 사용내역 상세 컨테이너 | 닫힘 / 열림(승인·진행중 구성 / 반려 구성 / 미작성 구성) |
| 결재선 지정 | 미지정 / 지정됨(템플릿 저장 여부는 최초 상신 성공 여부에 따름) |
