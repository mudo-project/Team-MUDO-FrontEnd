# Student(원생 관리) Domain — CONTEXT

> 배치 경로: `src/feature/student/CONTEXT.md`  
> 목적: 원생 관리 도메인의 범위와 화면 구성, 주요 기능 및 사용자 흐름을 파악하기 위한 문서이다.

---

## 1. 도메인 개요

원생 관리 도메인은 학원에 소속된 학생의 정보를 등록·조회·수정·삭제하고, 각 학생의 수강 강의를 관리하는 기능을 담당한다.

사용자는 원생 목록에서 학생의 기본 정보와 수강 현황을 확인할 수 있다. 원생 상세 화면에서는 학생 정보를 관리하고 새로운 강의를 등록하거나 기존 강의의 수강을 종료할 수 있다.

---

## 2. 진입점 및 라우팅

- Sidebar의 `원생관리` 메뉴를 클릭하면 원생 관리 페이지로 이동한다.
- 원생 관리 페이지는 검색 및 등록 기능이 있는 상단 영역과 원생 목록 영역으로 구성한다.
- 원생 목록의 항목을 클릭하면 해당 학생의 상세 조회 모달을 연다.

---

## 3. 원생 관리 페이지

### 상단 영역

다음 기능을 제공한다.

- 원생 이름 검색
- 원생 등록

### 원생 목록

원생 목록의 각 항목에는 다음 정보를 표시한다.

| 항목 | 설명 |
| --- | --- |
| 원생 이름 | 학생의 이름 |
| 학교 | 학생이 재학 중인 학교 |
| 학년 | 학생의 현재 학년 |
| 학생 연락처 | 학생 전화번호 |
| 학부모 연락처 | 학부모 전화번호 |
| 수강 개수 | 현재 학생에게 등록된 수강 강의 수 |

- 원생 항목 전체를 클릭 가능한 영역으로 제공한다.
- 원생 항목을 클릭하면 해당 학생의 상세 조회 모달을 표시한다.

---

## 4. 원생 등록

원생 등록 기능에서는 다음 정보를 입력할 수 있다.

| 입력 항목 | 설명 |
| --- | --- |
| 이름 | 원생 이름 |
| 학교 | 재학 중인 학교 |
| 학생 전화번호 | 학생 본인의 연락처 |
| 학부모 전화번호 | 학부모 연락처 |
| 학년 | 학생의 현재 학년 |
| 특이사항 | 학생 관리에 필요한 추가 메모 |

등록이 완료되면 새로운 원생이 원생 목록에 반영되어야 한다.

---

## 5. 원생 상세 조회 모달

원생 목록에서 학생을 선택하면 상세 조회 모달을 표시한다.

### 학생 기본 정보

상세 모달에서 다음 정보를 확인할 수 있다.

- 이름
- 학교
- 학년
- 학생 전화번호
- 학부모 전화번호
- 특이사항

### 수강 정보

- 학생이 현재 수강 중인 강의를 확인할 수 있다.
- 학생이 수강할 새로운 강의를 등록할 수 있다.
- 현재 수강 중인 강의를 수강 종료 처리할 수 있다.

### 학생 관리 기능

- 학생 정보 수정
- 학생 삭제

---

## 6. 원생 정보 수정

원생 정보 수정 시 다음 항목을 변경할 수 있다.

- 이름
- 학교
- 학년
- 학생 전화번호
- 학부모 전화번호
- 특이사항

수정이 완료되면 원생 목록과 상세 조회 모달에 변경된 정보가 반영되어야 한다.

---

## 7. 원생 삭제

- 상세 조회 모달에서 학생을 삭제할 수 있다.
- 삭제가 완료되면 해당 학생을 원생 목록에서 제거한다.
- 삭제된 학생의 상세 조회 모달은 닫혀야 한다.

---

## 8. 수강 관리

### 수강 등록

- 상세 조회 모달에서 학생이 수강할 강의를 등록한다.
- 등록이 완료되면 해당 학생의 수강 강의 목록과 원생 목록의 수강 개수에 반영한다.

### 수강 종료

- 학생이 현재 수강 중인 강의를 종료할 수 있다.
- 수강 종료가 완료되면 상세 모달의 수강 상태와 원생 목록의 수강 개수에 반영한다.

---

## 9. 주요 사용자 흐름

### 원생 등록

```text
Sidebar 원생관리 클릭
→ 원생 관리 페이지 이동
→ 원생 등록 선택
→ 학생 정보 입력
→ 등록 완료
→ 원생 목록 갱신
```

### 원생 상세 조회 및 수정

```text
원생 목록에서 학생 선택
→ 상세 조회 모달 표시
→ 학생 정보 확인
→ 학생 정보 수정
→ 수정 완료
→ 목록 및 상세 정보 갱신
```

### 수강 관리

```text
원생 상세 조회 모달 표시
→ 수강 강의 확인
→ 수강 강의 등록 또는 수강 종료
→ 수강 목록 및 수강 개수 갱신
```

---

## 10. 완료 조건

- Sidebar에서 원생 관리 페이지로 이동할 수 있다.
- 이름으로 원생을 검색할 수 있다.
- 원생의 기본 정보를 입력해 새로운 학생을 등록할 수 있다.
- 원생 목록에서 학생 정보와 수강 개수를 확인할 수 있다.
- 원생 항목을 클릭해 상세 조회 모달을 열 수 있다.
- 상세 모달에서 학생 기본 정보와 수강 강의를 확인할 수 있다.
- 학생 정보를 수정하고 목록과 상세 화면에 변경 내용을 반영할 수 있다.
- 학생을 삭제하고 목록에서 제거할 수 있다.
- 학생의 수강 강의를 등록하거나 수강 종료할 수 있다.
